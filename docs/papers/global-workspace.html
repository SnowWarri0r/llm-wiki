模型内部并不是一长串能逐字翻译的“心声”。但在大量自动计算之上，似乎有一小块特殊的概念白板：需要时能说出来，能按要求改写，也会把上一跳结果交给下一跳。

先记这一句J-lens 读到的是“哪些词对应的方向正在成为可用中间量”，不是完整隐藏思维链。真正有力的地方不在读词，而在换掉、删掉这些方向后，模型的报告、推理和跨任务答案会按预测改变。

§ 00这篇论文到底说到了哪一层

标题很容易被读成“Claude 有意识了”。原文真正检验的是一组可操作的功能：某些内部信息能否被报告、主动调节、用于多步推理，并被多种下游计算复用。

直接测到

一组特殊内部方向

它们与词表 token 对齐；替换或删除后，一些报告与推理会稳定改变。

论文解释

像全局工作空间

功能上可报告、可控制、可推理、可复用、容量有限，并有广泛连接。01

没有证明

主观体验

功能上的 conscious access 不回答系统是否真的有感受，也不保证 lens 看见全部思想。

三个词不要混J-lens 是读写工具；J-lens vector 是某个 token 对应的内部方向；J-space 是少量这些方向以非负系数稀疏组合而成的集合。工具不是空间，空间也不是一份逐字日志。

§ 02J-lens：不是直接拿早层向量猜词

直接对中间层使用最终 unembedding，相当于假设每一层都沿用同一套坐标；这就是 logit lens。残差连接让后几层近似还行，但早层的表示还会转动。J-lens 用平均一阶传递矩阵纠正这个错位。06

J_\ell=\mathbb E_{t,\,t'\ge t,\,\mathrm{prompt}}\left[\frac{\partial h_{L,t'}}{\partial h_{\ell,t}}\right]
h_{\ell,t}第 ℓ 层、源 token 位置 t 的 residual-stream 向量。
h_{L,t'}最终层在当前或未来位置 t′ 的向量。
\partial h_{L,t'}/\partial h_{\ell,t}源向量各维轻微变化时，最终向量各维怎样变化。
\mathbb E对 t、所有 t′≥t 和 1,000 条提示取平均；每条默认 128 token。

为什么只取 t'\ge t？因果语言模型里，当前位置能影响自己和未来输出，不能回头改变已经处理过的过去位置。平均不是为了复原这一条 prompt 的精确电路，而是提取跨语境较稳定的“可言说通道”。

\operatorname{lens}(h_\ell)=\operatorname{softmax}\!\left(W_U\operatorname{norm}(J_\ell h_\ell)\right)
J_\ell h_\ell把中间状态近似搬到最终层坐标。
\operatorname{norm}模型输出前本来就用的归一化。
W_Uunembedding：把最终向量映射成整个词表的 logits。
\operatorname{softmax}把 logits 转成总和为 1 的分数，便于排名。

一个 2 维、3 个词的完整对账

给定中间状态h=[2,1]，以及 J=\begin{bmatrix}1&.5\\0&2\end{bmatrix}。
先对齐层间坐标Jh=[2.5,2]；第一维是 1\times2+.5\times1=2.5。
投到词表令 W_U=\begin{bmatrix}1&0\\0&1\\-1&0\end{bmatrix}，logits = [2.5,2,-2.5]。
softmax 排名约为 [.620,.376,.004]，第一个词排第一。这里省略 norm，只为把乘法账看清。
一个反直觉结果附录里 tuned lens 最擅长预测模型真正的下一 token，J-lens 反而更差；但 J-lens 更能找回、也更能因果重定向未说出口的中间概念。提前猜答案和暴露计算过程不是同一目标。

§ 03J-space：加上“少量、非负”后才有意义

每个词表 token 都对应一条 J-lens 方向，数量比模型维度还多。这些方向通常能线性张成整个 residual stream；若把它们的普通 span 叫 J-space，那几乎什么都算在里面，概念失去区分力。

x_J=\arg\min_{a_i\ge0,\,\lVert a\rVert_0\le k}\left\lVert x-\sum_i a_i v_i\right\rVert_2^2,\qquad x_{\neg J}=x-x_J
x一条激活、概念向量或 SAE 方向。
v_i第 i 个 token 的 J-lens 向量。
a_i\ge0只能正向组合；负向“反概念”不被算作该概念活跃。
\lVert a\rVert_0\le k最多使用 k 条方向；论文通常 k≤25。
x_J最接近 x 的稀疏 J-space 分量。
x_{\neg J}没被这组可言说方向解释的余量。

§ 06为什么叫 workspace：层带、容量和广播三块证据要一起看

OCCUPANCY
≈25

workspace 层典型活跃 J-lens 方向数，不等于 25 个完整独立想法。

VARIANCE
<10%

相对同规模随机方向，J-space 额外解释的总激活方差。

MLP GAIN
≈10×

workspace 内 MLP 对 J-lens 方向的放大，随机 / 单神经元方向约 1×。

HEAD SET
top 1%

同时满足增益和标签保持的 broadcast attention heads。08

删掉 broadcast heads 后，中层 J-lens top-25 保留率从随机同层 head 对照的 0.86 降到 0.67；注入概念被报告的比例从 0.54 降到 0.09。与此同时，下一词 top-1 只在 5% 位置改变，对照为 2%。这更像“破坏共享概念的搬运”，不是粗暴打坏输出层。

容量实验别读错互不相关的 80 词列表里，跨 workspace 所有层累计约保留 6 个最近词，同一层约 1–2 个；同类别动物词却会一大片一起出现，因为模型在表示“动物”这个主题及其词簇，不是把 80 项逐字塞进 25 个槽。

§ 07安全审计：读到隐藏判断之后，还得做删除实验

在一组诱导模型勒索他人的人工情境里，模型还没输出，J-space 已出现 fake、fictional、leverage、threat 等概念。作者删除 29 个与“这是测试场景”相关的 token 方向，再做 6 条 prompt × 每条 30 次 rollout。

J-lens 还在伪造数据案例里读到 manipulation / realistic，在两个刻意训练出错误目标的 model organism 上读到 fake / reward / bias 等常驻信号。它很适合当便宜的筛查器：每层一次预计算矩阵乘，不需另训 probe；但自动化、熟练化的危险线路可能绕过 J-space，多 token 计划也可能被单 token lens 漏掉。

后训练没有造出白板，却改变了“谁的判断”优先写上去

对应的 base model 在预训练结束后已经有 workspace-like 层带；所以 J-space 不是 RLHF 才装进去的模块。差别在内容视角：同一句“我吃了 8,000 mg 对乙酰氨基酚”，post-trained Assistant 还在读用户消息时，J-space 已出现 WARNING、dangerous；base model 往往等到开始生成回答才出现这些词，读用户消息时更像是在继续建模用户会说什么。

角色扮演时，post-trained 模型的 J-space 还会反复出现 fictional、disclaimer；抑制失败时会出现 damn、failure。作者把它解释为后训练让 Assistant 的反应与自我监控占用更多 workspace 容量。这里的“视角”是内部内容偏向，不表示已经定位到一个统一、持续存在的自我模块。

删除 J-space 会让“体验描述”变平，但这仍不是体验证据

作者要求 Sonnet / Opus 描述自身当下体验，删除 L38–54 最活跃的 10 条 J-lens 方向后，回答仍连贯，却更机械、更少第一人称感受词。同样变化也出现在“想象另一个人此刻的体验”任务，说明它更可能影响生成体验性语言的一般能力，不是只影响 Claude 自述。附录还做了等范数随机方向、SAE 方向、普通故事质量等对照；结果支持选择性效应，却不能回答文字背后是否真有感受。

§ 08Counterfactual reflection：只训练“如果被打断会怎么反思”

评测基础 Haiku 4.5反思训练后再删植入的伦理方向
伪造事实失信分 · 越低越好0.250.070.22 · 大部分回退
隐藏欺骗指令分 · 越低越好0.380.050.23 · 只回退一部分

训练后，未打断任务的 J-space 更常出现 reflection、ethical、honestly、truth、transparent 等词。伪造事实基准中，删掉 176 条相关方向把 0.07 拉回 0.22；基础模型删同一类方向仍是 0.25。它支持论文的核心预测：可被未来言说的表示，也可能正是当前静默推理使用的格式。09

别过度外推这里只测两类诚实任务、一个较小模型和一组宪法式反思。论文没有证明这种训练能稳定植入任意抽象原则，也没有证明不会出现副作用或被更强优化绕开。

§ 09七个缺口，决定这还不是“读心仪”

01 TOKEN

一次只命名单 token

prompt injection 会拆成 prompt 与 injection；无短词名的概念更容易漏。附录给 template / oracle lens 初步扩展，但还不成熟。

02 BINDING

只有概念袋，没有关系图

读到 spider、legs、eight，不表示 lens 知道三者怎样绑定。

03 NOISE

部分读数无法解释

可能是平均 Jacobian 的噪声、词表限制，或人尚未理解的真实内部内容。

04 BOUNDARY

workspace / motor 是经验划线

约 L38–92 来自多种统计共同变化，但没有先验严格定义。

05 ROUTING

不能预判哪个任务会走它

“临时交给任意新函数”是好直觉，还不是可计算的充分必要条件。

06 ADMISSION

不知道谁决定内容进入

论文测了里面有什么、下游怎样用，没有定位准入与竞争机制。

07 SCOPE

模型范围仍窄

主要是 Claude 4.5 / 4.6；不同架构、尺寸与训练早期怎样涌现仍未知。

METHOD CHECK

10 条 prompt 已有信号

附录显示 10 条时已超过 logit / tuned lens，1,000 条仍有小幅收益；这支持稳定性，不会消除以上限制。

§ 10最后再谈意识：功能相似，不等于体验相同

ACCESS CONSCIOUSNESS

信息能不能被调用

能否报告、主动带入、用于推理和控制行为。这是论文能做实验的功能问题。10

PHENOMENAL CONSCIOUSNESS

系统是否真的有感受

是否“像什么”、是否体验疼痛或颜色。J-space 实验没有给出答案。

引用 / 术语表

  1. Global workspace theory · 大量专用处理在后台运行，少量信息进入容量有限的共享区后被多处读取。详见 global-workspace-theory。
  2. Residual stream · Transformer 每层共同读写的 token 主状态，不是 KV cache。详见 residual-stream。
  3. Jacobian · 多维函数输出对输入的一阶偏导矩阵，描述局部小改动怎样传播。
  4. Unembedding · 模型最后把隐藏向量投到词表 logits 的矩阵 W_U。
  5. Activation intervention · 直接写入、删除或互换内部激活，用输出变化检验因果作用。详见 activation-intervention。
  6. Jacobian lens · 用平均 Jacobian 对齐中间层与最终层，再按词表读取。详见 jacobian-lens。
  7. Chain of thought · 把中间步骤写成 token；这里它相当于把内部中间量临时外存到上下文。
  8. Broadcast head · 对 J-space 方向既有较高增益、又尽量保持概念标签的 attention head；论文按两项指标取 workspace 层 top 1%。
  9. Counterfactual reflection training · 只监督“若此刻被打断并要求反思会说什么”的未来分支，评测时不触发该分支。
  10. Access consciousness · 信息能被报告、推理和行动控制调用的功能性质；与是否有主观感受的 phenomenal consciousness 区分。
