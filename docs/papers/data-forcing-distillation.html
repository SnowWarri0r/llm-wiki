Data-ForcingDistillation.

Siyi Chen · Shaowei Liu · Yixuan Jia · Zian Wang · Huan Ling · Qing Qu · Jun Gao

DMD 的老师一直只看学生自己的作品。DFD 做的事很小：偶尔让老师改看同条件的真实视频。小改动背后，是一项会和原梯度精确抵消的正则。

TL;DRDFD 是 DMD2 后面的短后训练。fake-score 仍看学生视频；冻结 teacher 按概率 p 改看真实视频。真实数据因此直接进入分布匹配梯度，而不是只通过 GAN 间接传话。推理时仍只留下四步学生。
§ 00 · COMPLETE MAP

先拼完整：只在训练时多出一条真实数据支路

先说它拿来干嘛。把 14B 的视频扩散模型蒸成 4 步，速度能快一个数量级，但蒸出来的学生会塌：同一句提示词换随机种子，出来的构图几乎一模一样；镜头也不爱动；画面还偏过饱和。DFD 是接在 DMD2 之后的一段很短的后训练（论文只跑 100–300 步），把真实视频直接塞进分布匹配的主梯度，把丢掉的多样性和镜头运动找回来一部分。需要它的人是手上已经有 DMD2 蒸馏产物、想补质量和多样性的；不用它的替代办法是挂个 GAN 让真实数据间接传话，或者认了这份损失。

如果只盯着那行 teacher_data = data if rand() < p else gen_data，很难知道它为什么有效。先看一轮训练的五站数据流。

不变的部分DFD 没有替换学生架构，也没有把真实视频当逐像素标签。teacher、fake-score、加噪和伪目标都来自 DMD21；变的只是 teacher 本轮读取哪条视频。
§ 01 · FAILURE MODE

反向 KL 为什么看不见学生漏掉的花样

DMD 最小化反向 KL2。式子里最值得盯住的不是 \log，而是那个下标——求平均用的样本从谁那里抽：

p_{\mathrm{fake}}
学生输出的概率分布。
p_{\mathrm{real}}
老师代表的目标视频分布。
\mathbb E_{\tilde x\sim p_{\mathrm{fake}}}对 学生抽出来的样本求平均——这个下标就是整节的关键。
\log\frac{p_{\mathrm{fake}}}{p_{\mathrm{real}}}在某个位置上，学生给的概率比老师给的高出几倍（取对数）。

「反向」指的就是这个抽样方向：括号里第一个写的是 p_{\mathrm{fake}}，平均也按它抽。反过来那种（按 p_{\mathrm{real}} 抽）叫正向 KL，后面会拿来对照——两者差别大到一个有限、一个无穷。

先把期望摊成加权求和

「期望」在离散情形就是按概率加权求和：每个位置算一遍括号里的东西，再乘上抽到这个位置的概率，最后加起来。抽样来自 p_{\mathrm{fake}}，所以权重就是 p_{\mathrm{fake}}：

权重和被加权的东西用的是同一个 p_{\mathrm{fake}}——这一点马上会出事。把世界简化成只有两种构图：

两项各自的三个数都对得上表格：近景那项，权重是学生概率 1，括号里是学生 1 比真实 0.5；远景那项，权重是学生概率 0，括号里是 0/0.5。

远景那一项不能硬算，要取极限

\log 0 是负无穷，0\times(-\infty) 没有定义。正确做法是让学生给远景的概率 q 从正数一点点逼近 0，看整个式子往哪儿去。注意学生概率要归一，近景那格同时变成 1-q：

学生 = [1−q, q]      真实 = [.5, .5]      对数取自然对数

  q       近景项 (1−q)·ln((1−q)/.5)   远景项 q·ln(q/.5)      合计
 .1              +0.529008                 −0.160944       0.368064
 .01             +0.676266                 −0.039120       0.637146
 .001            +0.691455                 −0.006215       0.685240
 q→0             +0.693147                 −0.000000       0.693147 = ln 2

远景项的绝对值虽然在涨（ln(q/.5) 一路往负无穷跑），但前面那个权重 q
缩得更快，乘出来反而趋于 0。不是 ln(0) 等于 0，是「0 乘一个爆炸量」被压住了。
单项可以是负的，总和不会。远景那三个数都带负号，看着像“负代价”——那只是因为学生在那儿给的概率低于真实（比值小于 1，对数为负）。KL 是所有项加起来才有意义，合计那一列始终是正的，而且随 q\to 0 单调涨到 \ln 2 就不动了。

关键对照：换成正向 KL，同一件事的代价是无穷

0.693 到底算大还是算小？得有个参照。把抽样方向换过来——权重改用真实概率，比值也倒过来——同一组 q 再算一遍：

  q       近景项 .5·ln(.5/(1−q))   远景项 .5·ln(.5/q)      合计
 .1             −0.293893              +0.804719        0.510826
 .01            −0.341548              +1.956012        1.614463
 .001           −0.346073              +3.107304        2.761231
 q→0            −0.346574                  → +∞          → ∞

差别全在远景那一项的权重上：
  反向 KL 用学生概率 q 当权重 —— q→0，这一项自己消失
  正向 KL 用真实概率 .5 当权重 —— 权重不动，而 ln(.5/q) 冲向无穷

这就是「反向」两个字的全部后果：学生漏掉一整种构图，反向 KL 只罚 0.693 就到顶；正向 KL 会罚到无穷。0.693 相当于什么概念——它就是「两种构图只剩一种」这件事在反向 KL 眼里的全部代价，一个常数，梯度也随之消失。

换句话说，反向 KL 的权重是学生自己给的：学生没去过的地方，权重是 0，也就没有梯度把它拽回去。这就是模式塌缩3的根——训练只在学生到过的地方问路。DFD 要做的，正是想办法让真实数据那一侧也能出声。

证据边界这条采样逻辑直接解释“漏模式为什么没有信号”。论文还把视频过饱和归入反向 KL 的 mode-seeking 结果；实验支持 DFD 能缓解它，但过饱和不是上面两个格子的数学例子单独证明出来的。
§ 02 · THREE NETWORKS

先分清三套网络，score 才不会像凭空出现

扩散里的 score4不是“视频得 82 分”，而是与视频 latent 同形状的修改方向：

s_p(x)分布 p 在位置 x 给出的 score。
p(x)样本 x 附近的概率密度；不是分类置信度。
\log p(x)把概率密度取自然对数，便于把乘法关系变成加法关系。
\nabla_x对输入 x 的每个元素求偏导，得到同形状的方向场。

p(x) 是位置 x 附近的概率密度；\nabla_x 表示“对输入 x 的每个元素求梯度”。结果和视频 latent 同形状：每个位置都有一个“往哪改更像数据”的方向。

这两套 score 网络都不是临时凭空造出来的。它们先做同一类扩散训练，只是训练数据不同。先认符号，再看式子：

xteacher 用真实视频；fake-score 用学生刚生成的视频。
\alpha_t时刻 t 还保留多少原视频信号。
\sigma_t时刻 t 要混入多少噪声。
\epsilon本次实际采到的标准高斯噪声。
f_\phi正在训练的扩散网络；\phi 是它的参数。
c,\ t文本或首帧条件，以及当前噪声时刻。
y_t^{*}该 backbone 原本使用的扩散标签，例如噪声或速度；星号表示目标，不是乘法。
x=2, α=.8, σ=.6, ε=−.5
xt = .8×2 + .6×(−.5)
   = 1.6 − .3
   = 1.3

网络就是在这种带噪位置上练习“该往哪改”。

网络吐出来的不是 score，还得换一步

这一点容易被跳过：扩散网络的输出并不是 score，它预测的是 y_t^{*}（噪声、速度，看 backbone 而定）。score 要再换算一次。以最常见的「预测噪声」为例，换算式来自加噪定义本身：

换算的起点是这一行，它凭什么成立要先讲清：

p_t(x_t\mid x)竖线读作「在 x 已知的前提下」：钉住某一条具体视频，看它在时刻 t 加噪后会落在哪。
\mathcal N(\mu,\Sigma)高斯分布，前一格是均值 \mu，后一格是协方差 \Sigma。
I单位矩阵。出现在协方差那一格，意思是各分量独立、抖动幅度一样。

三步就能推出来，全部来自上面那条加噪定义 x_t=\alpha_t x+\sigma_t\epsilon：

① 除了 \epsilon，右边全是常数。\alpha_t,\sigma_t 是事先排好的调度表，x 被条件钉住了——所谓「给定 x」就是把它当固定数值看。整个式子里唯一还在随机的只有 \epsilon。

② 高斯乘常数、加常数，还是高斯。\epsilon\sim\mathcal N(0,I) 是一团标准噪声；乘 \sigma_t 是按比例放大缩小，加 \alpha_t x 是整体平移。钟形还是钟形，只是换了位置和胖瘦。

③ 均值和方差直接算。这两格各只用一条最基本的规则。先把工具摆出来（c 表示常数，A,B 表示随机量）：

\mathbb E[A]期望：把 A 反复采无穷多次，取这些值的平均。
\mathbb E[c]=c常数没有随机性，平均下来还是它自己。
\mathbb E[cA]=c\,\mathbb E[A]常数可以拎到期望外面。
\mathbb E[A+B]=\mathbb E[A]+\mathbb E[B]加减可以拆开算，各算各的再合。

用之前先认清谁是常数：\alpha_t x 整块是常数（调度表给定 \alpha_t，条件钉住 x），\sigma_t 也是常数，只有 \epsilon 是随机量。四条规则挨个用下去：

最后一步的 \mathbb E[\epsilon]=0 不是推出来的，是「标准」高斯这个词的定义：\mathcal N(0,I) 第一格写的就是均值 0，曲线对称地压在 0 两边，正的负的一样多，平均下来抵消。

四次采样验一遍（x_t = 1.6 + .6ε）

   ε        x_t
 −0.5      1.30
 +1.0      2.20
 +0.3      1.78
 −0.8      1.12
 ──────────────
 ε 的平均   = (−.5 +1 +.3 −.8) / 4 = 0 / 4 = 0
 x_t 的平均 = (1.3 +2.2 +1.78 +1.12) / 4 = 6.4 / 4 = 1.6   ← 正好是 α_t x

ε 的平均没落在 0 上时，x_t 的平均也跟着偏，偏多少完全由 σ_t 放大：
 只取前三个：ε 平均   = .8 / 3 = .2667
             x_t 平均 = 1.6 + .6 × .2667 = 1.76

所以「均值 = α_t x」说的是采无穷多次的平均；有限几次只会在 1.6 附近晃。

方差那一格为什么要乘平方。方差量的是「每个样本离均值有多远」的平方的平均。x_t 的偏离量是 \epsilon 偏离量的 \sigma_t 倍——x_t-\alpha_t x=\sigma_t\epsilon，一平方，倍数就变成 \sigma_t^2：

最后一步用的仍是「标准」的定义：\epsilon 各分量方差都是 1、彼此不相关，写成矩阵正好是 I。而 \alpha_t x 那块只是整体平移，不改变任何样本离均值的距离，对方差没有贡献。

用上面同样四个样本量一遍（这条不用取极限，任何一组样本都成立）

 ε   离它均值的偏离：−.5, +1, +.3, −.8
   平方后平均 = (.25 + 1 + .09 + .64) / 4 = .495

 x_t 离它均值的偏离：−.3, +.6, +.18, −.48   （每个都正好是上面那行的 .6 倍）
   平方后平均 = (.09 + .36 + .0324 + .2304) / 4 = .1782

 .1782 / .495 = .36 = .6²    ← 乘常数 .6，方差就乘 .36，跟采到哪几个 ε 无关

真正的标准高斯 Var(ε)=1，所以 Var(x_t) = .36 × 1 = .36，标准差 .6。
两格填回去：p_t(x_t|x) 就是「中心在 1.6、标准差 .6」的那根钟形曲线。
上面那张表里的 x_t=1.3、2.20、1.78、1.12 都只是这根曲线上的样本点，不是分布本身。

I 那一格在管什么（换成两维才看得出来）：x=[2, −1]
  均值   = [1.6, −.8]
  协方差 = .36 × [[1,0],[0,1]] = [[.36,   0],
                                 [  0, .36]]
           对角线两个数相等 → 每个分量抖得一样多
           非对角是 0       → 分量之间不相关，噪声各自独立地加
反过来看更能体会这个条件有多关键。把条件去掉，p_t(x_t)（不指定是哪条视频）是全体真实视频各自加噪后的钟形曲线叠在一起——一团没有闭式表达的东西，score 只能拿网络去拟合。给定 x 之后它才退化成一根干净的高斯，score 才能像下面这样手写出来。这也正是扩散训练能有监督标签的原因：单条样本的那一步是算得出来的。

有了这根高斯，score 就是纯代数了。高斯的密度取对数以后是个二次式，跟 x_t 无关的部分归到常数里，求导时直接消失：

对 x_t 求导：外层 -1/(2\sigma_t^2) 是常数拎着不动，里层平方求导给出 2(x_t-\alpha_t x)，一个 2 上下约掉——

最后把加噪定义代回去。x_t-\alpha_t x 按定义本来就等于 \sigma_t\epsilon，分子分母各约掉一个 \sigma_t：

这一步的意义是把 score 换成了网络真正会输出的东西：网络给出的是对 \epsilon 的估计 \hat\epsilon，代进去就得到可以直接算的 s=-\hat\epsilon/\sigma_t。

接着上面那个例子：x_t=1.3，α_t x=1.6，σ=.6，网络这一步估出 ε̂ = −.5

按均值算：s = −(1.3 − 1.6) / .36 = .3 / .36 = +.8333
按噪声算：s = −ε̂ / σ = −(−.5) / .6         = +.8333   ✓ 两条路对上了

正号说明「往正方向改更像数据」—— 因为噪声把它往负方向拽了 .3，
score 就指回来。这个 +.8333 才是后面 g_DMD 里 s_real / s_fake 的那种量。
换成别的 backbone，换算式不同但思路一样。预测速度（v-prediction / flow matching）的网络要按各自的 \alpha_t,\sigma_t 关系重新解一次，得到的仍是同一个 \nabla_x\log p_t。本页后面只用「score = 某个和 latent 同形状的方向场」这一层，不依赖具体哪种 backbone。

三套网络的起点在哪

容易漏掉的一环：student 和 fake-score 不是随机初始化的，它们开局都是 teacher 的副本。这是 DMD 就定下的做法——学生沿用老师的网络结构、直接复制参数，fake-score 同样复制一份。所以「三套网络」实际是一个 teacher 生出的两个分身：一个分身学着几步出图，另一个分身专职追踪第一个分身当前的分布。

backbone（Wan2.1-1.3B / Cosmos 2B）
   已在真实视频上做完普通多步扩散训练
        │
        ├─→ 自己留下不动         = teacher（real-score），全程冻结
        ├─→ 拷一份权重           = student Gθ
        └─→ 再拷一份权重         = fake-score
                  │
                  ├── DMD2 阶段：这两份一起训 25K 步
                  │
                  └── DFD 阶段：接着上面那对 checkpoint 往下走，只再跑 100–300 步

换句话说 DFD 拿到手的从来不是那份原始拷贝，而是已经被 DMD2 训过的一对。这正好解释了 § 07 那个最硬的负结果：跳过 DMD2、让 student 直接从 teacher 的原始拷贝开跑 DFD，训练 1400 次仍然失败——那时学生离真实视频太远，teacher discrepancy 的方差压不住。

§ 03 · DMD BASELINE

原始 DMD：两套 score 都在学生视频的位置回答

z\sim\mathcal N(0,I)学生的随机输入。
c文本、首帧或自回归历史条件。
t,\alpha_t,\sigma_t,\epsilon噪声时刻、信号比例、噪声比例和实际噪声。

式子右边那个 J_\theta=\nabla_\theta G_\theta(z,c) 就是生成器 Jacobian6——学生输出对它自己参数的导数：参数动一点，输出跟着动多少。前半截 (s_{\mathrm{fake}}-s_{\mathrm{real}}) 说的是“视频该往哪改”，乘上它才变成“参数该往哪改”，这就是链式法则的最后一环。梯度下降会减去 gDMD，所以模型靠近 real score，同时避开学生已经堆得过密的位置。

s_fake=.2, s_real=1.0, Jθ=.5
视频空间的差 = .2−1.0 = −.8
参数梯度     = −.8×.5 = −.4

若 θ=1、学习率=.1：
θnew = 1−.1×(−.4) = 1.04

Jθ 为正时，θ 增大让输出沿 real 指向的方向移动。
§ 04 · CORE SIGNAL

Teacher score discrepancy：同一位老师，两处回答之差

竖线 |c 表示条件已经固定。文本是“海边奔跑的狗”，真实视频也要对应这条描述；I2V 时，真实视频必须匹配输入首帧。它不是随手抓一条无关视频。

第一项让老师站在真实视频处回答，第二项让同一位老师站在学生视频处回答。二者相减，问的就是：“从学生现在的位置挪到真实数据常出现的位置，老师的修改建议会变多少？”

假设匹配后，两边都以 .5 概率落到 A / B：
teacher(A)=+1，teacher(B)=−1

真实支路平均 = .5×1 + .5×(−1) = 0
学生支路平均 = .5×1 + .5×(−1) = 0
两边平均之差 = 0−0 = 0

所以学生已经匹配真实分布时，两处样本虽然不必逐个相同，但它们来自同一分布，teacher discrepancy 在期望上自动归零。详见 teacher-score-discrepancy。

§ 05 · EXACT CANCELLATION

为什么一项正则最后能化成一行输入替换

DFD 先写成“原 DMD 梯度减去 teacher discrepancy”：

sfake(学生)=.2, sreal(学生)=1.0, sreal(真实)=.4, Jθ=.5

gDMD     = (.2−1.0)×.5        = −.40
Δteacher = .4−1.0             = −.60
gDFD     = −.40−(−.60×.5)     = −.10

短公式   = (.2−.4)×.5         = −.10  ✓ 对上
§ 06 · ONE-LINE CHANGE

代码改的是 teacher 输入，不是把真实视频拿去直接回归

随后 fake-score 仍读取加噪学生视频，teacher 读取加噪后的 teacher_data。两者做差，乘一个归一化因子，再造伪目标：

vsd_grad      = (fake_score − teacher_score) × w_norm
pseudo_target = gen_data − vsd_grad
loss          = 1/2 · MSE(gen_data, stopgrad(pseudo_target))

stopgrad7把右边钉成本轮固定目标，只准左边的学生输出移动。它不会冻结整套学生。

那个 w_norm 是干什么的

两套 score 之差的绝对尺度是不受控的：噪声时刻不同、视频内容不同，这个差可能大几十倍，也可能几乎为零。直接拿它当步长，训练就时快时慢。w_{\mathrm{norm}} 把这个差按“学生现在离老师多远”除一遍，让每步挪动的相对幅度稳定下来：

分母那个 10^{-6} 只防除零。差得远时 w_{\mathrm{norm}} 小、单步收着走；已经很近时它变大，但乘上本来就很小的 score 差，净效果仍是小步。

这一项是实现层的，不在论文正文的公式里。参考实现里除的是“老师给出的干净预测”与“学生输出”之间的逐样本平均绝对距离；下面把整段视频压成一个标量，所以这两个量在数值上共用了同一个 teacher=1.0——真实代码里它们是两个不同的张量。看数量级和方向可以，别当成论文公式。

从伪目标算到一次更新

下面用一个标量代替整段视频，并临时设 \partial gen/\partial\theta=1。这样可以把“学生参数改变一点，输出也改变一点”简化成一比一，方便只看伪目标方向；真实网络仍要通过 Jacobian 把输出梯度传回参数。

§ 07 · VALIDITY CONDITION

为什么共享噪声，为什么 DFD 必须放在 DMD2 后面

若两边各采一份噪声，差值里还会多出 \sigma (\epsilon_{\mathrm{real}}-\epsilon_{\mathrm{fake}})，teacher discrepancy 会混入无关波动。

论文进一步要求：固定条件后，真实样本与学生样本的平均平方距离不能太大。

还要求 teacher score 别太“陡”。Lipschitz8 就是给“陡”定一个上限——输入挪多远，输出最多跟着挪多远：

比如 L=1.5 的意思是：两个输入相差 1，teacher 给出的方向最多相差 1.5。有了这个上限，才能把“输入差多少”翻译成“方向差多少”。再加上生成器 Jacobian 最多放大 B 倍，论文给出误差上界：

\delta(c)固定条件 c 后，学生视频离真实视频通常有多远。
L(c,t)输入挪动一格时，teacher score 最多变化多少。
B视频空间的方向传回参数时，Jacobian 最多放大多少倍。
\alpha_t加噪后还保留多少原视频信号。

这条上界像四级扩音器：学生与真实数据先差 \delta；teacher 的方向变化把它放大 L 倍；加噪只留下 \alpha_t 份信号；最后 Jacobian 再放大 B 倍。任一环很大，DFD 的近似就可能偏；学生已经靠 DMD2 走近真实数据时，最关键的 \delta 才足够小。

这就是 post-training 的理由DFD 先要一名已经会生成合理视频的 DMD2 学生。跳过 DMD2、直接从 teacher 初始化时，真实与生成视频差得太远；论文训练 1400 次仍失败。DFD 是修复器，不是从零蒸馏器。
§ 08 · STOCHASTIC MIX

默认一半 DMD、一半 DFD，但不是每轮都跑两遍

当 p=w，随机二选一的长期平均等于加权和。若 gDMD=- .4、gDFD=- .1、p=.5，期望就是 .5\times (- .4)+.5\times (- .1)=- .25。论文默认 p=.5。

§ 09 · DATA CURATION

真实数据一旦进入主梯度，数据集就成了方向来源

聚类不是装饰：直接随机抽样容易让大簇和近重复视频占满 batch。DFD 会沿参考数据的 score 学习，批次重复或条件错误，模型就会把这些偏差也学进去。

“real data” 不等于全部实拍论文里的 real 是相对学生分布而言的参考数据。ViPE-Wild-1M 的源视频由 Wan2.1-14B 生成；DFD 证明的是“让参考数据直接进入梯度”有效，不能外推成只靠自然实拍视频恢复了真实世界分布。

CFG 是提示词条件强度：数值越大，生成结果通常越紧跟条件，但太大也可能损伤画面自然度。这里记录的是论文训练配方，不代表所有模型都该用同一个 CFG。

论文版本不一致arXiv 摘要写 100–300 steps，正文 v2 §1 仍残留 50–100。表 4 与官方复现命令支持 100 / 300，本页按可复现配置记录。
代码默认值不等于论文配方官方配置类里的 gen_real_replace_prob 默认是 .25；README 的 DFD 训练命令会显式覆盖为 .5。复现时应看最终命令，而不是只读配置类默认值。
论文说删 GAN，公开命令却没有关论文表 4 把 DFD 的判别器学习率标成 N/A，并用消融说明 GAN 没有一致收益；但官方 commit 7281906 的 README 命令没有覆盖 Wan / Cosmos 配置继承的 gan_loss_weight_gen=.03，还加载 discriminator。照当前命令运行会继续使用 GAN，除非显式把权重设为 0。
≤2 步仍吃力快动作模糊、脸部细节丢失，还可能塌成近乎静止。
依赖高质量匹配数据条件错、覆盖窄或重复多，真实数据支路也会给错方向。
理论有前提teacher score 平滑、Jacobian 有界，且真实/生成样本已经接近。
多样性未追平老师T2V 表里 teacher 的多样性与镜头终点距离仍更高。
AR 证据主要定性结构案例更稳，但缺少完整量化主表。
安全风险仍在加速也会扩大深伪和误导内容的产能；DFD 本身没有安全过滤。

我的判断

DFD 最漂亮的地方不是代码短，而是理论先找到一项能与 DMD 原梯度精确抵消的正则，才把复杂改动压成 teacher 输入的一行替换。它也说明“用真实数据”不是一句空话：真实样本进入哪一条梯度，决定它是 GAN 的间接意见、逐样本回归，还是分布匹配里的直接方向。

REFERENCE · GLOSSARY

术语与延伸阅读

  1. DMD / DMD2 · 用 real / fake score 匹配生成分布；DMD2 补高频 fake 更新、GAN 和多步训练。dmd2
  2. Reverse KL · KL(pfake||preal)，平均值按学生样本计算，因此偏向学生已经覆盖的模式。entropy-kl
  3. Mode collapse · 输入噪声不同，生成结果却集中在少数构图或运动模式。
  4. Score function · \nabla_x\log p(x)；不是分数，而是样本空间里的局部修改方向。score-function
  5. Fake-score network · 在线去噪器，用学生最新输出训练，近似 pfake 的 score。
  6. Jacobian · 输出对参数的导数；把视频 latent 的修改方向通过链式法则传回模型参数。
  7. Stop-gradient · 前向保留数值，反向把该支路当常数；它只切断这条支路的梯度，不会冻结整套学生。
  8. Lipschitz · 输入变化多少，输出最多变化多少的上界；这里用来控制 teacher score 的放大倍数。
  9. GAN · 判别器在真假样本之间学习分类，再把对抗梯度传给生成器；论文说 DFD 可以删除它，但当前公开命令仍保留非零权重。
  10. CLIP / DINO diversity · 同提示词不同种子的视频先变成特征，再以成对余弦差异衡量视觉多样性。
  11. VBench · 视频生成评测套件；主体、背景、闪烁、运动、美学等分项不能互相替代。
  12. WebDataset · 把大规模样本打进 tar 分片，训练时顺序流式读取，减少海量小文件开销。
