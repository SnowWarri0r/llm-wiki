Data-ForcingDistillation.

Siyi Chen · Shaowei Liu · Yixuan Jia · Zian Wang · Huan Ling · Qing Qu · Jun Gao

DMD 的老师一直只看学生自己的作品。DFD 做的事很小：偶尔让老师改看同条件的真实视频。小改动背后，是一项会和原梯度精确抵消的正则。

TL;DRDFD 是 DMD2 后面的短后训练。fake-score 仍看学生视频；冻结 teacher 按概率 p 改看真实视频。真实数据因此直接进入分布匹配梯度，而不是只通过 GAN 间接传话。推理时仍只留下四步学生。
§ 00 · COMPLETE MAP

先拼完整：只在训练时多出一条真实数据支路

如果只盯着那行 teacher_data = data if rand() < p else gen_data，很难知道它为什么有效。先看一轮训练的五站数据流。

不变的部分DFD 没有替换学生架构，也没有把真实视频当逐像素标签。teacher、fake-score、加噪和伪目标都来自 DMD21；变的只是 teacher 本轮读取哪条视频。
§ 01 · FAILURE MODE

反向 KL 为什么看不见学生漏掉的花样

DMD 最小化反向 KL2。公式最值得盯住的不是 log，而是平均值按谁抽样：

p_fake
学生输出的概率分布。
p_real
老师代表的目标视频分布。
\widetilde{x}\sim p_{\mathrm{fake}}用于求平均的样本来自学生。

这里不能把 log 0 当成普通数字算。正确做法是让学生给远景的概率 q 从正数慢慢逼近零，再看整项 q\log(q/0.5) 的极限：

q=.1    → .1×ln(.1/.5)    ≈ −.161
q=.01   → .01×ln(.01/.5)  ≈ −.039
q=.001  → .001×ln(.001/.5)≈ −.006

q 越接近 0，整项越接近 0；不是 ln(0) 本身等于 0。

学生把“远景”彻底漏掉，反向 KL 仍只有有限代价，因为这一格的权重也跟着学生概率一起缩到零。这就是模式塌缩3的根：训练只在学生到过的地方问路。

证据边界这条采样逻辑直接解释“漏模式为什么没有信号”。论文还把视频过饱和归入反向 KL 的 mode-seeking 结果；实验支持 DFD 能缓解它，但过饱和不是上面两个格子的数学例子单独证明出来的。
§ 02 · THREE NETWORKS

先分清三套网络，score 才不会像凭空出现

扩散里的 score4不是“视频得 82 分”，而是与视频 latent 同形状的修改方向：

p(x) 是位置 x 附近的概率密度；\nabla_x 表示“对输入 x 的每个元素求梯度”。结果和视频 latent 同形状：每个位置都有一个“往哪改更像数据”的方向。

这两套 score 网络都不是临时凭空造出来的。它们先做同一类扩散训练，只是训练数据不同：

xteacher 用真实视频；fake-score 用学生刚生成的视频。
\alpha_t/\sigma_t/\epsilon保留多少原视频、加入多少高斯噪声，以及本次噪声。
f_\phi正在训练的扩散网络；\phi 是它的参数。
c,\ t文本或首帧条件，以及当前噪声时刻。
y_t^{*}该 backbone 原本使用的扩散标签，例如噪声或速度；星号表示目标，不是乘法。
s_p(x)根据网络预测和噪声参数换算出的 \nabla_x\log p_t(x)。
x=2, α=.8, σ=.6, ε=−.5
xt = .8×2 + .6×(−.5)
   = 1.6 − .3
   = 1.3

网络就是在这种带噪位置上练习“该往哪改”。
§ 03 · DMD BASELINE

原始 DMD：两套 score 都在学生视频的位置回答

z ~ N(0,I)
学生的随机输入。
c
文本、首帧或自回归历史条件。
t,\alpha_t,\sigma_t,\epsilon噪声时刻、信号比例、噪声比例和实际噪声。

J_\theta 是生成器 Jacobian6：它负责把“视频该怎样改”的方向传回参数。梯度下降会减去 gDMD，所以模型靠近 real score，同时避开学生已经堆得过密的位置。

s_fake=.2, s_real=1.0, Jθ=.5
视频空间的差 = .2−1.0 = −.8
参数梯度     = −.8×.5 = −.4

若 θ=1、学习率=.1：
θnew = 1−.1×(−.4) = 1.04

Jθ 为正时，θ 增大让输出沿 real 指向的方向移动。
§ 04 · CORE SIGNAL

Teacher score discrepancy：同一位老师，两处回答之差

竖线 |c 表示条件已经固定。文本是“海边奔跑的狗”，真实视频也要对应这条描述；I2V 时，真实视频必须匹配输入首帧。它不是随手抓一条无关视频。

第一项让老师站在真实视频处回答，第二项让同一位老师站在学生视频处回答。二者相减，问的就是：“从学生现在的位置挪到真实数据常出现的位置，老师的修改建议会变多少？”

假设匹配后，两边都以 .5 概率落到 A / B：
teacher(A)=+1，teacher(B)=−1

真实支路平均 = .5×1 + .5×(−1) = 0
学生支路平均 = .5×1 + .5×(−1) = 0
两边平均之差 = 0−0 = 0

所以学生已经匹配真实分布时，两处样本虽然不必逐个相同，但它们来自同一分布，teacher discrepancy 在期望上自动归零。详见 teacher-score-discrepancy。

§ 05 · EXACT CANCELLATION

为什么一项正则最后能化成一行输入替换

DFD 先写成“原 DMD 梯度减去 teacher discrepancy”：

sfake(学生)=.2, sreal(学生)=1.0, sreal(真实)=.4, Jθ=.5

gDMD     = (.2−1.0)×.5        = −.40
Δteacher = .4−1.0             = −.60
gDFD     = −.40−(−.60×.5)     = −.10

短公式   = (.2−.4)×.5         = −.10  ✓ 对上
§ 06 · ONE-LINE CHANGE

代码改的是 teacher 输入，不是把真实视频拿去直接回归

随后 fake-score 仍读取加噪学生视频，teacher 读取加噪后的 teacher_data。两者做差，再造伪目标：

vsd_grad     = fake_score − teacher_score
pseudo_target = gen_data − vsd_grad
loss          = 1/2 · MSE(gen_data, stopgrad(pseudo_target))

stopgrad7把右边钉成本轮固定目标，只准左边的学生输出移动。它不会冻结整套学生。

从伪目标算到一次更新

下面用一个标量代替整段视频，并临时设 \partial gen/\partial\theta=1。这样可以把“学生参数改变一点，输出也改变一点”简化成一比一，方便只看伪目标方向；真实网络仍要通过 Jacobian 把输出梯度传回参数。

gen=1.2, fake=.8, teacher=1.0
wnorm ≈ 1/|1.2−1.0| = 5
vsd_grad = (.8−1.0)×5 = −1.0
target   = 1.2−(−1.0) = 2.2
L        = 1/2×(1.2−2.2)² = .500
dL/dgen  = −1.0

学习率 .1：gennew=1.2−.1×(−1)=1.3
旧靶验方向：Lnew=1/2×(1.3−2.2)²=.405  ✓ 下降
§ 07 · VALIDITY CONDITION

为什么共享噪声，为什么 DFD 必须放在 DMD2 后面

若两边各采一份噪声，差值里还会多出 \sigma (\epsilon_{\mathrm{real}}-\epsilon_{\mathrm{fake}})，teacher discrepancy 会混入无关波动。

论文进一步要求：固定条件后，真实样本与学生样本的平均平方距离不能太大。

若 teacher score 是 L(c,t)-Lipschitz8，生成器 Jacobian 最多放大 B 倍，则：

\delta(c)固定条件 c 后，学生视频离真实视频通常有多远。
L(c,t)输入挪动一格时，teacher score 最多变化多少。
B视频空间的方向传回参数时，Jacobian 最多放大多少倍。
\alpha_t加噪后还保留多少原视频信号。
\|\cdot\|_2^2各分量平方后求和，表示整体误差大小。
左边
DFD 近似梯度与理想 KL 梯度之间的差。

这条上界像四级扩音器：学生与真实数据先差 \delta；teacher 的方向变化把它放大 L 倍；加噪只留下 \alpha_t 份信号；最后 Jacobian 再放大 B 倍。任一环很大，DFD 的近似就可能偏；学生已经靠 DMD2 走近真实数据时，最关键的 \delta 才足够小。

B=.5, α=.8, L=1.5, δ=.5
上界 = .5²×.8²×1.5²×.5²
     = .09
这就是 post-training 的理由DFD 先要一名已经会生成合理视频的 DMD2 学生。跳过 DMD2、直接从 teacher 初始化时，真实与生成视频差得太远；论文训练 1400 次仍失败。DFD 是修复器，不是从零蒸馏器。
§ 08 · STOCHASTIC MIX

默认一半 DMD、一半 DFD，但不是每轮都跑两遍

当 p=w，随机二选一的长期平均等于加权和。若 gDMD=- .4、gDFD=- .1、p=.5，期望就是 .5\times (- .4)+.5\times (- .1)=- .25。论文默认 p=.5。

§ 09 · DATA CURATION

真实数据一旦进入主梯度，数据集就成了方向来源

聚类不是装饰：直接随机抽样容易让大簇和近重复视频占满 batch。DFD 会沿参考数据的 score 学习，批次重复或条件错误，模型就会把这些偏差也学进去。

“real data” 不等于全部实拍论文里的 real 是相对学生分布而言的参考数据。ViPE-Wild-1M 的源视频由 Wan2.1-14B 生成；DFD 证明的是“让参考数据直接进入梯度”有效，不能外推成只靠自然实拍视频恢复了真实世界分布。

§ 12 · RECIPE & LIMITS

训练账、版本差异和还没解决的问题

Wan T2V

81 帧 · 480p · batch 16
student / fake LR 1e-5
CFG 5.0 · 8×A100
DMD2 25K → DFD 100 次

Cosmos I2V

81 帧 · 480p · batch 16
student / fake LR 1e-5
CFG 3.0 · 16×A100
DMD2 25K → DFD 300 次

CFG 是提示词条件强度：数值越大，生成结果通常越紧跟条件，但太大也可能损伤画面自然度。这里记录的是论文训练配方，不代表所有模型都该用同一个 CFG。

论文版本不一致arXiv 摘要写 100–300 steps，正文 v2 §1 仍残留 50–100。表 4 与官方复现命令支持 100 / 300，本页按可复现配置记录。
代码默认值不等于论文配方官方配置类里的 gen_real_replace_prob 默认是 .25；README 的 DFD 训练命令会显式覆盖为 .5。复现时应看最终命令，而不是只读配置类默认值。
论文说删 GAN，公开命令却没有关论文表 4 把 DFD 的判别器学习率标成 N/A，并用消融说明 GAN 没有一致收益；但官方 commit 7281906 的 README 命令没有覆盖 Wan / Cosmos 配置继承的 gan_loss_weight_gen=.03，还加载 discriminator。照当前命令运行会继续使用 GAN，除非显式把权重设为 0。
≤2 步仍吃力快动作模糊、脸部细节丢失，还可能塌成近乎静止。
依赖高质量匹配数据条件错、覆盖窄或重复多，真实数据支路也会给错方向。
理论有前提teacher score 平滑、Jacobian 有界，且真实/生成样本已经接近。
多样性未追平老师T2V 表里 teacher 的多样性与镜头终点距离仍更高。
AR 证据主要定性结构案例更稳，但缺少完整量化主表。
安全风险仍在加速也会扩大深伪和误导内容的产能；DFD 本身没有安全过滤。

我的判断

DFD 最漂亮的地方不是代码短，而是理论先找到一项能与 DMD 原梯度精确抵消的正则，才把复杂改动压成 teacher 输入的一行替换。它也说明“用真实数据”不是一句空话：真实样本进入哪一条梯度，决定它是 GAN 的间接意见、逐样本回归，还是分布匹配里的直接方向。

REFERENCE · GLOSSARY

术语与延伸阅读

  1. DMD / DMD2 · 用 real / fake score 匹配生成分布；DMD2 补高频 fake 更新、GAN 和多步训练。dmd2
  2. Reverse KL · KL(pfake||preal)，平均值按学生样本计算，因此偏向学生已经覆盖的模式。entropy-kl
  3. Mode collapse · 输入噪声不同，生成结果却集中在少数构图或运动模式。
  4. Score function · \nabla_x\log p(x)；不是分数，而是样本空间里的局部修改方向。score-function
  5. Fake-score network · 在线去噪器，用学生最新输出训练，近似 pfake 的 score。
  6. Jacobian · 输出对参数的导数；把视频 latent 的修改方向通过链式法则传回模型参数。
  7. Stop-gradient · 前向保留数值，反向把该支路当常数。stop-gradient
  8. Lipschitz · 输入变化多少，输出最多变化多少的上界；这里用来控制 teacher score 的放大倍数。
  9. GAN · 判别器在真假样本之间学习分类，再把对抗梯度传给生成器；论文说 DFD 可以删除它，但当前公开命令仍保留非零权重。
  10. CLIP / DINO diversity · 同提示词不同种子的视频先变成特征，再以成对余弦差异衡量视觉多样性。
  11. VBench · 视频生成评测套件；主体、背景、闪烁、运动、美学等分项不能互相替代。
  12. WebDataset · 把大规模样本打进 tar 分片，训练时顺序流式读取，减少海量小文件开销。
