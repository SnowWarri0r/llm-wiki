Diffusion Architecture · Field Notes

Diffusion
U-Net.

Jonathan Ho et al. · Alex Nichol & Prafulla Dhariwal · Robin Rombach et al. · 2020–2022

它不是“给经典 U-Net 喂一张噪声图”这么简单。同一套权重要在纯噪声、模糊轮廓和细节收尾三个阶段做不同工作，还要接收文字、保住空间位置，最后只输出这一步该去掉什么。这一页把整台机器拆开，再用同一组数字从训练走到恢复。

TL;DR

扩散 U-Net 每次接收带噪图或 latent、时间步和条件，经过多尺度 ResBlock、skip connection 与 attention，输出一张同尺寸的噪声图或速度图。U-Net 只给方向；scheduler 才负责走到下一步。采样时二者循环配合，直到噪声变成图像。

00 / MAP先把完整拼图摆出来

一次调用只走中间这一横排。真正的“生成”来自它被反复调用：状态更新后，新的 x_{t-1} 又回到最左边。

三件东西别混：扩散过程规定怎样加噪、训练目标是什么；U-Net是学会预测的神经网络；扩散时刻01告诉它当前噪声有多重；scheduler13把网络输出换成下一步状态。换 DDIM、Euler 或 DPM-Solver，常常是在换最后一件，不是在重训一套 U-Net。

01 / FAMILY经典 U-Net 留下骨架，扩散模型换了工作

真正保留下来的，是“压缩空间尺寸来理解全局，再放大恢复位置，并把同尺度细节横向送过去”这套组织方式。DDPM 在此基础上加入 GroupNorm03、正弦时间嵌入和 self-attention；ADM 把条件调制与注意力做得更稳；LDM 又把计算搬进 latent，并用 cross-attention 接文字。块内那条短捷径属于 ResBlock05，不要和跨越整个 U 形的 skip 混为一谈。

02 / TRAINING PAIR老师答案不是人工标注，而是我们刚加进去的噪声

训练前先拿干净样本 x_0，随机抽一个时间步 t 和一份高斯噪声 \epsilon。用已知公式把噪声混进去，得到网络输入 x_t。因为噪声是我们亲手抽的，它天然就是监督答案；每个时刻的混合比例由噪声日程02预先规定。

x_0干净图像或干净 latent；下标 0 表示轨迹起点。
t随机抽到的噪声时刻；越靠后通常越接近纯噪声。
\bar{\alpha}_t到时刻 t还保留多少原信号；由 noise schedule 预先给定。
\epsilon本次随机采样的标准高斯噪声，也是最常见的训练目标。
x_t混合后的带噪输入，形状与 x_0完全相同。
\sqrt{\cdot}用标准差而不是方差缩放，使两部分方差按预定比例相加。

前向加噪：把干净信号和噪声按当前时刻的比例混合

x_t=\sqrt{\bar{\alpha}_t}\,x_0+\sqrt{1-\bar{\alpha}_t}\,\epsilon

噪声预测损失：网络猜的噪声与真实噪声逐元素比较

L_\epsilon=\mathbb{E}_{x_0,t,\epsilon}\!\left[\left\lVert\epsilon-\epsilon_\theta(x_t,t,c)\right\rVert_2^2\right]
\epsilon_\theta参数为 \theta 的 U-Net；输入带噪状态、时刻和可选条件 c。
\lVert\cdot\rVert_2^2所有位置误差平方后相加；标量例子里就是普通平方。
\mathbb{E}对许多图、时刻和噪声取平均；一次小批训练只是在估计这个平均值。
c可选条件；可为类别、文字 token，也可为空条件。
为什么不是让网络直接输出最终图？ 预测我们刚加进去的噪声，老师答案精确、无限生成，而且每个噪声强度都能制造训练对。预测 x_0 或速度 v 也可行；那是目标参数化12的变化，不要求把 U-Net 骨架推倒重来。

03 / TENSOR MAP以 Stable Diffusion v1 为例，把尺寸账走一遍

512×512 RGB 图先经 VAE 压缩 8 倍，变成 64×64×4 latent。官方配置的基础通道数是 320，通道倍率是 [1,2,4,4]，因此四个尺度分别是 320、640、1280、1280 通道。

每个尺度有两个 ResBlock。配置里的 attention_resolutions = [4, 2, 1] 很容易读反：这里列的是相对 64×64 latent 的下采样倍率，所以实际 attention 位于 16×16、32×32、64×64。Stable Diffusion v1 的 U-Net 约 860M 参数；它比经典分割 U-Net 大得多。

04 / RESBLOCK一块里同时做空间处理、时间调制与安全回退

guided-diffusion 的典型块先用 GroupNorm + SiLU04 + 卷积处理空间特征，再把时间向量投影成缩放和偏移，最后经零初始化卷积写回残差支路。

AdaGN10 / scale-shift normalization：让同一份特征随时刻改变处理方式

h'=(1+s_t)\odot\operatorname{GN}(h)+b_t
h这一 ResBlock 的中间空间特征。
\operatorname{GN}(h)GroupNorm 后的特征；按单样本、分组统计，不依赖 batch 大小。
s_t由时间嵌入生成的逐通道缩放；代码用 1+s_t，让零缩放表示“不改变”。
b_t由时间嵌入生成的逐通道平移。
\odot逐元素相乘；每个通道用自己的缩放值。
h'经过当前时刻调制、准备继续卷积的特征。

把公式完整代一遍。若 \operatorname{GN}(h)=[-1,1]，当前时刻给两个通道的缩放 s_t=[0.5,-0.5]，平移 b_t=[0.2,0.1]，那么：

h'=(1+[0.5,-0.5])\odot[-1,1]+[0.2,0.1]=[-1.3,0.6]

第一通道是 1.5\times(-1)+0.2=-1.3，第二通道是 0.5\times1+0.1=0.6。若另一个时刻给出 s_t=b_t=0，输出就退回 [-1,1]。所以时间条件改变的是每个通道放大多少、平移多少，并不是把时间数字贴到图像旁边。

SiLU 是什么？ \operatorname{SiLU}(x)=x\,\sigma(x)，其中 \sigma(x)=1/(1+e^{-x})。它像一道平滑的门：正数大多通过，负数不是一刀切为 0，而是保留少量连续信号。

05 / TIME为什么一套权重能应付不同噪声强度

如果不告诉网络时间步，同一个数值模式可能既代表“纯噪声里偶然出现的边”，也代表“末期图像里该保留的真边”。DDPM 把离散时刻做成时间嵌入06：编码成一串不同频率的正弦 / 余弦，再过 MLP，送进每个 ResBlock。

正弦时间编码的一对分量

\operatorname{emb}_{2i}(t)=\sin(t\,\omega_i),\qquad \operatorname{emb}_{2i+1}(t)=\cos(t\,\omega_i)
t当前扩散时刻；可为离散步编号或连续噪声时间。
i频率编号；每个编号生成一对 sin / cos 分量。
\omega_i第 i 个预设频率；不同频率同时刻画粗、细时间差。
\operatorname{emb}(t)时间向量；过 MLP 后投影成各 ResBlock 需要的通道数。

用两个频率把编码真的算出来。取 t=2、\omega_0=1、\omega_1=0.1：

\operatorname{emb}(2)=[\sin2,\cos2,\sin0.2,\cos0.2]\approx[0.909,-0.416,0.199,0.980]

高频那一对随时间变化快，低频那一对变化慢；合在一起，邻近时刻仍相似，相隔很远的时刻又能区分。后面的 MLP 会把这四个数映射成各 ResBlock 所需的 s_t 和 b_t；MLP 权重是训练出来的，所以这里不伪造它的具体输出。

06 / SKIPskip 传的不是“答案”，而是同尺度的定位线索

下采样越深，网络越懂“这是一只猫”，却越难记住胡须准确落在哪个像素。skip connection09把编码器同尺度特征缓存下来，在解码器恢复到相同高宽时按通道拼接。

它对反复去噪尤其合适：每一步都要输出与输入同尺寸的像素 / latent 修正。如果所有高分辨率信息都被迫穿过 8×8 瓶颈，细节得先压扁再凭空还原；skip 给了更短的保真路线。注意它和 ResBlock 的 residual add 不同：U-Net skip 常用 concat，ResBlock 捷径常用 add。

07 / SELF-ATTENTION卷积看附近，attention 让远处位置直接对话

卷积通过一层层堆叠扩大感受野；self-attention07则让任意两个位置一步交换信息。它有利于让左右眼一致、重复窗户对齐、远处物体遵守同一构图，但代价随位置数的平方增长。

所以 DDPM 的 256×256 模型在 16×16 插一次全局 attention。ADM 用更系统的消融，把 attention 扩到 32×32、16×16、8×8，并采用多头。Stable Diffusion v1 算在 64×64 latent 上，空间已经比 512×512 像素小 8 倍，因此能在更多尺度加入 spatial transformer。

08 / CROSS-ATTENTION文字不是贴在图旁边，而是被每个图像位置主动查询

LDM 把 U-Net 的图像特征摊成位置 token，做 Query；文字编码器输出做 Key / Value。某个图像位置先问“哪些词和我最相关”，再按权重取回对应的文字信息。

QQuery；来自图像 U-Net 当前层的空间位置。
KKey；来自文字 token，用于计算每个词与该位置的匹配度。
VValue；真正按权重取回并写入图像位置的文字内容。
d每个 attention head 的向量维度；除以 \sqrt d避免点积随维度变大而过分尖锐。
K^\topKey 矩阵转置，使每个图像 Query 能与所有文字 Key 做点积。
\operatorname{softmax}把一排匹配分数转成和为 1 的非负权重。

缩放点积注意力

\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V

把最后一步展开：第一维是 0.670\times2+0.330\times0=1.34，第二维是 0.670\times0+0.330\times4=1.32。这也说明 attention 输出不是“67% 猫”这个标签，而是按相关性混合后的内容向量。真实模型当然不止两个词和二维向量；关键方向要记牢：图像位置发问，文字 token 提供可检索的 Key 和真正写回的 Value。self-attention 是图像位置彼此交流；cross-attention08是图像去查外部条件。

09 / LOOP训练只抽一个时刻，采样才把许多时刻串起来

训练：一次随机抽题

  1. 取干净样本 x_0
  2. 随机抽时刻 t 与噪声 \epsilon
  3. 直接算出 x_t
  4. U-Net 前向一次，算 MSE
  5. 反向传播更新参数

采样：沿时间轴连续答题

  1. 从纯噪声 x_T 开始
  2. U-Net 预测当前噪声 / 速度
  3. scheduler 算出下一状态
  4. 换新时刻，再调用同一 U-Net
  5. 重复直到得到 x_0

由预测噪声反推当前干净样本估计

\hat{x}_0=\frac{x_t-\sqrt{1-\bar{\alpha}_t}\,\hat{\epsilon}}{\sqrt{\bar{\alpha}_t}}
\hat{\epsilon}U-Net 对本次噪声的预测；帽子表示估计值。
\hat{x}_0根据当前状态和预测噪声反推出的干净样本估计。
x_t当前带噪状态；不是网络最终要显示的图片。
\bar{\alpha}_t仍是该时刻的保真比例；与训练加噪公式使用同一套 schedule。

沿用 §02：x_t=1.3、\bar{\alpha}_t=0.64。若网络猜 \hat{\epsilon}=-0.3，则 \hat{x}_0=(1.3-0.6\times(-0.3))/0.8=1.85；若猜对 -0.5，就恢复到原值 2。

U-Net 不自己决定步长。 它给出局部方向或噪声估计；scheduler 决定用多大的步、是否加入随机性。classifier-free guidance14则在同一时刻组合有条件与无条件预测，放大提示词造成的差值。

LIMIT 01

U 形多尺度很适合图像，但卷积局部偏置可能限制大规模模型的 scaling。

LIMIT 02

高分辨率 attention 昂贵；latent diffusion 缓解了计算，却把细节上限部分交给 VAE。

LIMIT 03

反复调用同一大网络仍慢；蒸馏、缓存和少步求解器解决的是循环成本，不是单个 U-Net 块。

术语就地补课

  1. Diffusion timestep · 扩散时刻：表示当前状态处在“几乎纯噪声”到“几乎干净”的哪一段，不是网络层编号。
  2. Noise schedule · 噪声日程：预先规定各时刻保留多少原信号、加入多少噪声的一组系数。
  3. GroupNorm：在单个样本内部按通道分组做归一化，不依赖 batch 统计；适合显存受限的小 batch 生成训练。详见 GroupNorm。
  4. SiLU：x\sigma(x)，又常叫 Swish；是一种平滑、非单调的激活函数。
  5. ResBlock：主变换之外保留一条输入捷径并相加；复杂分支学不到有用变化时，至少容易退回恒等映射。
  6. Timestep embedding：把标量时间步编码成高维向量，再投影给每个 ResBlock。详见 时间条件。
  7. Self-attention：同一组图像位置互相做 Q/K/V；用来建立远距离空间关系。
  8. Cross-attention：一组 token 发 Query，另一组提供 Key/Value；LDM 里图像位置查询文字。详见 cross-attention。
  9. Skip concat：编码器与解码器同尺度特征沿通道维拼接；高宽不变、通道相加。详见 skip connection。
  10. AdaGN / scale-shift norm：条件向量不只相加，而是生成归一化后的缩放和平移，让每个时刻改写通道行为。
  11. VAE latent：图像经编码器压缩后的连续特征；Stable Diffusion v1 把 512×512 图压到 64×64×4，再在这里去噪。
  12. Parameterization：网络输出目标的定义；常见为噪声 \epsilon、干净样本 x_0 或速度 v。
  13. Scheduler / sampler：读取网络预测和当前状态，按选定数值规则算下一状态；DDPM、DDIM、Euler、DPM-Solver 属于这一层。
  14. Classifier-Free Guidance：组合有条件与无条件输出，放大条件造成的方向差。详见 CFG。
  15. DiT：用 Transformer 取代扩散 U-Net 的预测骨架；并不自动等于 flow matching。详见 DiT 精读。
