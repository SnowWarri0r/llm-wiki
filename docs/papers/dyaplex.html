Full-duplex speech × dyadic body motion

DYAPLEX.

DyaPlex · Full-Duplex Speech-Motion Model for Dyadic Interaction

机器人正在回答时，你忽然摆手，它不能等整段录音结束才“配动作”。DyaPlex 让语音、对方身体和自己的身体每 80 毫秒共同往前走。

TL;DR

冻结 PersonaPlex 语音塔；把双方动作交错成每帧 46 个 token；所有同帧 token 共享真实时间编号，逐层 cross-attention 读取同频语音状态。主实验只做身体骨架，不直接生成像素。

SECTION 00不是“听完再配动作”，而是持续闭环

用户说“箱子太重了”并弯腰指向地面。普通 co-speech 模型拿完整录音配一段动作；DyaPlex 必须在用户刚弯腰时就让智能体转向、回应，同时继续听下一句话。

输出边界：主模型输出通用 SMPL-X02 身体姿态，不含皮肤、衣服和背景；脸部版本仅作定性演示。它是动作架构，不是直接像素视频模型。

SECTION 01冻结语音塔，新增动作塔：权重没有“变成骨骼”

PersonaPlex 是 32 层、宽 4096 的因果语音 Transformer，Mimi codec 以 12.5 Hz 推进。DyaPlex 冻结它，并为每一层接一层新的 motion Transformer。动作塔宽 1024，16 个 self-attention head；cross-attention 有 12 头、每头 64 维。

SECTION 0225 FPS 连续姿态怎样压成 22 个离散选择

四个严格因果 RVQ-VAE03分别负责上身、手、下身与位移、脸。编码器时间降采样 2 倍，把 25 FPS 变成与语音相同的 12.5 Hz；解码器再还原到 25 FPS。

这种表示把一次姿态拆成 22 次局部选择。优点是不同身体部位可独立压缩；缺点是每 80 毫秒要顺序采样 22 个码，论文也把它列为主要效率瓶颈。

SECTION 03把双人动作写成一条序列，模型才看得见“你动我才动”

每一帧的扁平长度：

K=22每个人每个 12.5 Hz 帧的动作码数。
+1每个人前面额外插入身份标签。
L_{step}=46一个真实时间帧在扁平序列里占 46 个 token。

SECTION 0446 个 token 是一帧，不是 46 个时间点

若用扁平下标做位置，同帧首尾相差 45，相邻帧边界却只差 1。语音每 80 毫秒只有一格，这种位置会把身体部位顺序误当时间。

先把扁平位置还原为真实帧：

t动作长序列里的扁平 token 下标。
L_{step}=46每个真实帧的 token 数。
q_{pos}(t)送进 cross-attention RoPE 的真实帧编号。

例如 t\in[92,137] 时，所有位置都满足 \lfloor t/46\rfloor=2。它们属于同一个动作帧，应该共享时间位置 2。

SECTION 05Time-aligned RoPE05：让动作第 2 帧找到语音第 2 帧

动作 Query 与语音 Key 各按自己的真实时间旋转：

q_t当前动作 token 经训练投影得到的 Query。
K^\ell[s]语音塔第 ℓ 层、第 s 个时间片的 Key。
q_{pos}(t)-sRoPE 点积中真正起作用的相对时间差。
去掉会怎样：没有 cross-attention，动作只能听不到语音；有 cross-attention 但没有时间 RoPE，则要靠内容自己猜对齐。消融中去掉 cross-RoPE，FGD 由 5.6 变 8.4，BeatAlign 由 .059 变 .064。

SECTION 06训练预测下一个码，推理时只生成智能体槽

band mask06 后的 teacher forcing04 交叉熵：

\theta动作塔参数；语音塔冻结。
\mathcal S每帧 18 个受监督身体码位置。
x_{\le t}真实双人动作历史；teacher forcing 直接给模型。
\{H^\ell\}PersonaPlex 32 层隐藏状态。
p_\theta非法部位编号被 mask 后，正确码的概率。
-\log p正确概率越低，损失越大。

辅助 voice-activity BCE 判断说话/聆听状态，总目标为 \mathcal L=\mathcal L_{CE}+.01\mathcal L_{VA}。若正确码概率 .7、说话概率 .8 且标签为 1，则 -\ln(.7)=.3567，voice 项 .01[-\ln(.8)]=.00223，总计 .3589。

Both-speaker mode

为合成双人数据，同时采样 A 与 B 的动作槽。两个人都由模型创造。

Agent-only mode

把摄像头观测的搭档动作抄进 A 槽，只在 B 的 18 个身体位置采样。人物标签确定性插入。

SECTION 073435 小时数据怎样留下来

Seamless Interaction 原始约 4000 小时。横屏异常、旋转、不可读视频被删除；HMR2 约 2.4% 无效帧丢弃，少于 8 个有效帧的配对也丢弃。最终训练集 57,947 对 / 3435 小时；测试集 330 对 / 约 18 小时，取每对前 20 秒评测。

hybrid prompt 由默认文字角色说明和约 10 秒声音样本组成；约 1.4% 缺少可用声音提示的配对被过滤。面部分支用 SPECTRE 提取 6D 下巴旋转 + 50D 表情；零面部帧达到 20% 的配对不进入 face-codec 子集。

训练配置：AdamW，β₁=.9、β₂=.95、weight decay .1、L2 clip 1.0、lr 3e−4、有效 batch 512；64 张 H100、30k iteration。四个 part codec 各用 1 张 H100 单独训练。

SECTION 08先懂指标，再看“看对方”带来多大差异

FGD 只看智能体 22×3=66D 关节分布；Paired-FD07 把双方拼成 132D，检查互动配对。Diversity 与 BeatAlign 要接近 GT .633 / .049，不是盲目越高越好。 \Delta User=(PFD_{shuffled}-PFD_{matched})/PFD_{matched} 检查随机换搭档后是否恶化。matched 7.3、+31% 对应 shuffled 7.3\times1.31=9.563。

基线边界：DualTalk 从面部回归迁移到身体任务后明显崩塌。结果支持 DyaPlex 架构，但优势幅度也受基线重训质量影响。

SECTION 0980 毫秒预算：实时来自缩短动作历史

12.5 Hz 的单帧预算是 1/12.5=0.08\,s=80\,ms。A6000 Ada 上，论文分别报告语音塔 30 ms、decoder .8 ms、动作塔完整 4096-token context 为 173 ms；后者明显超预算。

SECTION 11局限与判断：强架构论文，不是完整数字人产品报告

01 · BODY ONLY主实验没有脸

face codec 仅有定性演示，不能从身体指标推出表情质量。

02 · TWO PEOPLE只支持双人

46-token 编排与同帧顺序都围绕 A/B。

03 · LATENCY没有端到端测量

组件 runtime 不含完整调度、I/O 与机器人执行。

04 · CONTEXT实时要缩历史

动作上下文从 7.1 秒降到 1.76 秒。

05 · SEQUENTIAL22 码逐个采样

论文建议未来改成 chunk/depth decoder。

06 · DEPLOYMENT未做真实机器人长期实验

测试是离线 Seamless 数据的前 20 秒。

我的判断：最可信的贡献是交错双人序列 + 真实时间 RoPE + agent-only 因果采样形成闭环；partner ablation 证明对方动作不是装饰。最该降温的是“real-time full character”：它依赖较短 motion context，主结果仍是双人身体骨架。

术语直达 · 点编号看人话解释

  1. 全双工：智能体输出期间仍接收对方输入，新输入可改变后续语音与动作；不只是首包低延迟。详见概念页。
  2. SMPL-X：用关节姿态、表情和形体参数驱动通用三维人体的参数模型；不是像素视频。
  3. RVQ-VAE：多个残差量化层把连续动作压成离散编号，再由解码器还原。详见概念页。
  4. teacher forcing：训练预测下一 token 时，前缀使用真实 token，而不是模型刚才可能预测错的 token。
  5. time-aligned RoPE：同一动作帧的 46 个 token 共享真实帧编号，与同频语音按相对时间做 attention。详见概念页。
  6. band mask：上身、手、下身、脸各只能在自己的 1024 编号区间选码；其他 logits 在 softmax 前设为负无穷。
  7. Paired-FD：把双方关节拼在一起比较联合动作分布，检查互动而不只是单人自然度。
