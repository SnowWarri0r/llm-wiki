多模态预训练 · 控制变量实验 · FAIR / META / OXFORD

三种能力，怎样一起长出来。

这篇写给正在从头训练统一图文模型的人：文字、看图和画图，谁在给谁铺路？模型该共享哪些参数，视觉该什么时候接入，三类数据该怎样分预算？没有这些规律，只能拿昂贵的预训练反复试错。“Physics” 不是物理定律，而是作者用控制实验寻找的可重复经验。

JUNLIN HAN · SHENGBANG TONG · DAVID FAN · MINGHAO CHEN · PHILIP TORR · FILIPPOS KOKKINOS · MIKE LEWIS
TL;DR知识流不对称：语言普遍帮助视觉，看图明显帮助画图，画图却很少零样本反哺前两者。联合训练里，attention 与 norm 适合共享来交流，FFN 适合按模态拆开来避免抢容量；视觉越晚接入，越容易被成熟语言主干“代做”。论文在自己的 1T 网格中找到 L/U/G=70/25/5，再用 13.5B MoE、2T token 验证。这里的 5% 是生成 token 份额，不是严格的 GPU 算力占比。

§ 00先把标题说人话：这里没有牛顿定律

论文想做的不是再造一个榜单模型，而是把“统一多模态预训练”拆成几道能做控制变量的题。

L · Language

纯文字

给前文，预测下一个 token。目标是文字交叉熵，主要看 accuracy 和 PPL。

U · Understanding

看图后说出来

图像输入，caption 或 VQA 答案输出。仍是文字交叉熵，但输入多了视觉 token。

G · Generation

读文字后画出来

文字输入，图像 latent 输出。目标换成 rectified flow / flow matching。

“Physics” 指的是：在数据、模型和预算都控制住时，某个现象能否反复出现。它更接近“经验规律”或“训练动力学”，不是已经证明对所有模型都成立的定律1。

全文主线先找 谁帮谁，再问帮助为什么会被容量竞争抵消，然后找出模型内部该共享什么、该拆开什么，最后才谈训练时机和数据比例。

§ 01完整拼图：同一个 Transformer 怎么同时读、看、画

控制实验的主干接近 Llama-3：16 层、隐藏维 2048，32 个 Query head、8 个 KV head；语言骨干约 1.5B，默认把图像与文字的 FFN 拆开后总参数约 2.3B。统一框架叫 Transfusion2：离散文字继续做 next-token，连续图像 token 在同一主干里做 flow matching。

四种视觉入口到底差在哪

默认方案把理解和生成放进同一组语义坐标；另外三组对照故意拆掉不同条件，用来检查知识流是不是某个 tokenizer 碰巧带来的。

RAE · 默认

理解、生成共用语义 latent

冻结 SigLIP-2 ViT-400m/14，把 224\times224 图像变成 16\times16=256 个语义 token。理解直接读取；生成在同一 latent 去噪，再由 RAE decoder 还原像素3。

Raw Pixels

拿掉预训练视觉先验

一层 14\times14 卷积直接切 224\times224 图像，仍得到 16\times16=256 个 patch；轻量 MLP 只负责对齐隐藏维。没有视觉 encoder，也没有 decoder。

CLIP + VAE

理解与生成改走两套坐标

理解仍读 SigLIP 的 256 个 token；生成改在 SD3 VAE 里处理 256\times256 图像，经 8 倍下采样得到 32\times32\times16 latent。这样可检验“共用 latent”是否必要。

AR · UniTok

连 diffusion 也换掉

图像先量化成离散码，再按空间位置自回归预测；每个位置还有 causal depth head，逐个预测残差量化的码本因子。若趋势仍在，就不能归功于 flow matching。

x-prediction 为什么能换成去噪速度

这段要回答两个问题：网络在时刻 t 看到什么，以及 Euler 采样器该沿哪个方向走。先把式子里的量全部认全：

x_0 · 想恢复的干净 latent
\epsilon · 与它同形状、现场采样的高斯噪声
t · 标量；0 在噪声端，1 在干净端
x_t · 在时刻 t 喂给网络的带噪 latent
v · 采样轨迹对时间的变化速度
1-t · 当前点离干净端还剩的时间

定义输入。直线路径把干净图和噪声按位置 t 混合：

x_t=t x_0+(1-t)\epsilon

推导速度。网络直接预测干净样本 x_0。从当前位置走到干净端，位移是 x_0-x_t，剩余时间是 1-t，所以先算“位移 ÷ 时间”。把输入定义代进分子：

x_0-x_t=x_0-\left[t x_0+(1-t)\epsilon\right]=(1-t)(x_0-\epsilon)

分子和分母都有 1-t，约掉后得到整条直线上的恒定速度：

v=\frac{x_0-x_t}{1-t}=x_0-\epsilon
给定x_0=2，\epsilon=-1，t=.25
插值得输入x_t=.25\times2+.75\times(-1)=-.25
换成速度v=(2-(-.25))/.75=3
自检直接算 x_0-\epsilon=2-(-1)=3，两条路一致。

当 t=1 时已经到达干净端，不再用上面的除法；训练的 logit-normal 采样落在开区间内，采样器也在到端点前计算速度。

生成 loss 还被乘以 3。记 r_L,r_U,r_G 为三类 token 的抽样份额，三者相加为 1；\mathcal L_L,\mathcal L_U,\mathcal L_G 分别是纯文字、视觉理解和视觉生成在各自样本上的单项损失。只看这两只旋钮，混合目标可粗略记成：

\mathcal L\approx r_L\mathcal L_L+r_U\mathcal L_U+3r_G\mathcal L_G

系数 3 是损失权重，不是第三种数据比例。因此“G 占 5%”不等于“生成梯度只占 5%”，也不等于只花 5% GPU 时间。

现在模型拼好了。下一步先学会读它的实验，否则“语言比例 80%”很容易被误会成从 50B 里切走了 80%。

§ 02怎样证明 A 帮了 B：固定基座，只加一种数据

知识流不是“一个模型会两件事”，而是目标能力的数据不变，只增加另一种训练，目标能力仍系统变好。

先约定两个量：A 是后来新增的另一种能力数据量，单位是 B（十亿）token；r 是这批新增 token 占最终总量的比例。目标能力的基座始终固定为 50B，因此有 r=A/(50+A)，移项后才得到下面的新增量公式。

语言尺子：PPL 是“平均像在几个选项里猜”

N · 被评分的 token 数
y_i · 第 i 个真值 token
y_{<i} · 它前面的真值前缀
p(y_i\mid y_{<i}) · 模型给真值的概率
-\log p · 这一步的“意外程度”
\exp · 把平均 log 损失还原成等效分支数

把每一步的“意外程度”取平均，再用指数函数撤销对数，就得到困惑度：

\mathrm{PPL}=\exp\!\left[-\frac1N\sum_{i=1}^{N}\log p(y_i\mid y_{<i})\right]
四步概率[.5,.25,.5,.25]
平均 NLL-(\ln .5+\ln .25+\ln .5+\ln .25)/4=1.0397
PPLe^{1.0397}\approx2.83，平均像在 2.83 个等可能选项里猜；越低越好。

Generation

DPG 看长描述遵循；GenEval 看组合约束；CLIP-Sim 看图文对齐；Diffusion loss 看验证集去噪误差。前三个越高越好，loss 越低越好。

初始化也属于控制变量这六个方向并不全从同一起点训练：L→U、L→G、U→L、G→L 都从头初始化；U→G 与 G→U 则从已经练过 50B 语言 token 的 checkpoint 起步，让模型先具备基本文字能力。所以下面的箭头比较的是“在作者各自设定的起点上，新增一种数据后目标能力怎样变化”，不是六次完全同初始化的对称实验。

§ 03知识流地图：三种能力不是等边三角形

真实数据用 DCLM 纯文本和约 3.5 亿 SSTK 图文对。每次固定一个 50B 基座，再把另一能力从 0% 扫到 80%。结果非常不对称4。

为什么语言连无条件画图都能帮

条件画图受益好理解：语言主干更会解析 prompt。更值得注意的是，无条件 diffusion loss 也下降。作者把它解释为语言学习到的世界结构能给视觉建模提供“模态无关”的先验。但这仍是经验观察，不代表模型内部真有一个被证明存在的统一世界坐标系。

为什么看图会让纯语言略退化

视觉理解数据里的文字不是 DCLM 网页正文，而是 caption、问题和短答案。加入大量 U token 同时改变了文字分布，所以语言 PPL 变差既可能来自容量竞争，也可能来自训练文本分布偏移。论文没有把两者完全拆开。

跨 tokenizer 复核附录在 Raw Pixels、CLIP+VAE 和 UniTok AR 上重复三组方向实验，仍得到 L 普遍帮视觉、U 明显帮 G、G 对 L/U 大致中性的趋势。知识流更像目标本身的属性，而不是 RAE 的独有副作用。
真实网页数据只能告诉我们“加了 U，G 变好了”，却说不清到底转移了什么。下一步把世界缩成几种颜色和积木，外科式删掉一个概念。

零样本不会，不等于内部什么都没学

作者从 held-out checkpoint 继续微调 2000 step，每 200 step 测一次。生成训练看过某种颜色/形状后，模型虽然不能立刻在 VQA 里说出它，却比“两个流都没见过”的 control 学得快，平均 accuracy 曲线面积提高约 +.133\text{ 到 }+.273。像素细节已经进了内部表征，只是还没接到文字答案接口。

反方向更弱：理解看过 yellow 并不能加速黄色生成；对形状只有小幅帮助。把一个物体压成“yellow”标签所需的稀疏语义，远少于真正画出黄色像素分布所需的密集信息。

评测边界每个概念只有 100 个样本，生成由单个 Qwen3-VL-8B 自动判官评分，论文没报告人工复核一致性。它适合看强趋势，不适合把 0.05 与 0.03 这种小差异当精确常数。

§ 05协同与竞争：一起练，为什么有时反而更好

联合模型里同时有两股力：共享表示让一种任务给另一种任务搭脚手架；有限参数又让两种高难任务抢容量。论文固定 100B token，语言/视觉各 50B，并与 50B 单模态基线比较5。

记 \mathrm{PPL}_{joint} 为语言与视觉联合训练后的语言困惑度，\mathrm{PPL}_{language\text{-}only} 为只用同样 50B 语言数据训练的基线；用前者减后者：

\Delta\mathrm{PPL}=\mathrm{PPL}_{joint}-\mathrm{PPL}_{language\text{-}only}

\Delta\mathrm{PPL}<0 表示加入视觉后语言更好，是净协同；\Delta\mathrm{PPL}>0 表示容量竞争压过协同。diffusion loss 差值同理，越负越好。

反方向也类似：固定 SSTK 图像，配最简单的重复字母语言，conditional / unconditional diffusion loss 改善 -.0153\,/\,-.0168；换成 nonsense 或完整 DCLM，仍有帮助，但幅度变小。

别把 complexity 当公式作者明确说这只是“大致的复杂度进阶”，不是严格或单调的测量。背景、噪声、OCR、视频、自然图之间不只难度变了，数据分布和任务结构也变了。可靠结论是“任务越吃容量，竞争越可能盖过协同”，不是“语义复杂度每增加 1，PPL 必涨多少”。

§ 06模型内部在哪里打架：FFN 分开，attention 留共享

作者把每个 Transformer block 拆成 Attention、FFN、FinalNorm 三组，逐组决定是共享还是按模态复制6。测试故意使用最容易出现协同的 simple language + pure background，让架构差异更显眼。

Shared Attention

保留“互相看见”

文字和图像 token 能在每一层交换上下文。拆掉 attention 后，两边改善明显缩水。

Shared Norm

保留共同标尺

让两种特征在可交流的数值尺度里流动。拆 norm 也会损失一部分协同。

Split FFN

各自消化细节

FFN 承担大量逐 token 特征变换，最吃容量；按模态分开，避免同一组参数硬记两套分布。

Raw Pixels 的语言 ΔPPL 甚至达到 -.266；CLIP+VAE 虽然理解和生成 latent 分开，生成 loss 仍改善约 -2.24\%\,/\,-2.83\%；UniTok AR 也有同向结果。预对齐共享 latent 有帮助，却不是协同出现的必要条件。

到这里，空间上的分工清楚了：共享交流通道，拆开容量仓。下一题是时间：这些通道什么时候开始一起练？

§ 07“越早越好”不能只靠一张曲线，要看三层证据

顺序训练也输：不是只要换个“人类成长顺序”

作者固定 L/U/G=50/25/25，试完全部六种顺序。无论先语言还是先视觉，严格分阶段训练几乎都不如同时联合。给后续阶段混入 12.5% 旧模态 replay，能减轻 catastrophic forgetting7，却仍追不上 joint baseline。这说明丢掉的不只是旧技能，还有训练全程本可获得的跨模态协同。这里的 early unification 指训练时机，不等同于必须删掉视觉编码器11。

§ 08Vision Laziness：图像在序列里，模型却越来越少用它

“懒”不是拟人化猜测。论文给相同的 200B 联合 continuation，再从训练激活、embedding、推理激活和 attention 四个角度找同一趋势8。

A训练 FFN L2训练 100k step 里，图像 FFN 输出有多“响”
BWrapper embedding L2图像起止 token 被语言空间接纳到什么幅度
C推理 FFN RMS真实生成 / 看图问答时，图像分支实际做多少计算
D图像 attention 占比query 的注意力究竟有多少落到图像 token

L2 和 RMS 为什么还要除一个 √n

设 h=[h_1,\ldots,h_n] 是某一层的输出向量，h_i 是第 i 个元素，n 是元素个数。L2 把所有元素的能量加总；RMS 再除以 \sqrt n，消掉“元素越多，L2 天然越大”的影响：

\lVert h\rVert_2=\sqrt{\sum_{i=1}^{n}h_i^2},\qquad \mathrm{RMS}(h)=\frac{\lVert h\rVert_2}{\sqrt n}
向量h=[3,4,0,0]，元素数 n=4
L2\sqrt{3^2+4^2}=5
逐元素 RMS5/\sqrt4=2.5；把“元素更多自然更大”的影响除掉。

“注意图像”是一个可直接相加的比例

下面是为了把论文的统计过程写清楚而整理的等价记号，并非论文另外提出的训练损失。A_{img} 表示“平均有多少注意力落在图像上”：

Q · 被考察的 query 集；生成时是图像 query，理解时是文字 query
I · 所有图像 key 的位置集合
a_{qk} · softmax 后从 query q 到 key k 的权重
|Q| · query 数，用来取平均
A_{img}=\frac1{|Q|}\sum_{q\in Q}\sum_{k\in I}a_{qk}

每个 query 的 attention 行本来就和为 1。把图像 key 对应的格子相加，就得到“这一行有多少注意力给了图像”；再对 query 平均即可。语言起点从 0B 推到 800B 时，中深层的这个比例明显下降，图像 FFN 激活也同步变小。

为什么会这样成熟语言主干已经会用 prompt 和常识走捷径。优化器要继续降 loss，沿用现成语言路径比重塑整套表示更容易；视觉分支收到的有效任务压力越来越小。最终模型能“靠题干猜”时，就更少认真读取图像。
不能只看一个 norm激活变小本身不等于模块无用；高效表征也可能幅度小。这里可信是因为四类内部读数与最终视觉指标一起下降。Vision laziness 仍是这组现象的机制解释，不是对所有架构已证明的定律。

§ 09配方不是三等分：70% 语言、25% 理解、5% 生成

前面的知识流告诉我们：L 和 U 都能给 G 铺路，G 却很少反向帮助 L/U。那么最省预算的做法应该是多练“上游”，只留足够的 G token 教会模型真正把内部先验变成像素。这就是非对称多模态配方的出发点10。

1T 搜索分三步：先让 L 从 10% 扫到 90%、其余 U/G 平分；再固定 L50 扫 U/G；最后固定 L70 精扫。总共 23 组。L70/U25/G5 得到 General 48.3、Vision-Centric 47.1、VQA Avg 38.5、DPG .450、GenEval .237。

数字别读过头最低 diffusion loss 实际在 L50/U5/G45，最低语言 PPL 在 L90/U5/G5。70/25/5 是作者按三类能力综合选的折中，不是每一列都赢，更不是换任何数据、视频或音频后仍固定不变的宇宙常数。

§ 10放大验证：13.5B MoE、每 token 只激活 1.5B

大规模模型有 256 个 FFN experts，每个 token 激活 16 个：2 个固定给语言 / 视觉模态，另外 14 个动态路由。Attention 与 norm 继续共享。这把小实验的“共享交流通道、拆开专用计算”自然放大成 MoE9。

≈1.5B active / token共享 attention / norm 继续交换信息

Full 少用五倍生成 token，语言、理解和提示对齐反而更好，但 diffusion loss 从 .261 变 .272，并非所有生成指标都赢。50k 图像 FID 是 5.234，对照 Balanced 为 5.131，接近但仍略差。

“架构单变量”也要带脚注MoE 是 13.5B 总参数 / 1.5B active，Dense 是 3.5B 总参数。每 token 活跃计算更接近，但总容量不匹配；结果支持稀疏大容量适合多模态分工，不能简化成“同参数量下 MoE 必胜”。

§ 11实验和基础设施：完整账本

控制模型16 层、hidden size 2048、32 个 Query head / 8 个 KV head；SwiGLU、RoPE θ=500k、pre-RMSNorm、QK-Norm、FlashAttention，FFN expansion=1.5。语言骨干约 1.5B，拆分 FFN 后总计约 2.3B。
优化器AdamW，β1=.9、β2=.95、weight decay=.1、gradient clip=1.0；前 8000 step 线性 warm-up，随后 cosine decay。
数值 / 并行bf16，FSDP-2，context length 4096。论文未报告 GPU 型号、数量、墙钟时间与能耗。
生成训练logit-normal 采样 t；x-prediction 转 velocity；flow loss 权重 ×3。
生成推理25-step Euler，CFG=5.0。
数据DCLM 纯文本；约 350M SSTK 图文对，同时供应 image→text 和 text→image。
VQA SFTCambrian-7M 一轮；AdamW，峰值学习率 1e−5，global batch 128，cosine decay。
复现控制初始化和 data iterator 固定 seed=0；评估 temperature=0。控制实验没有多 seed 方差。
语言11 项 few-shot/EM 汇总；DCLM in-domain PPL 与 C4 out-of-domain PPL。
视觉理解16 项，汇成 General / Knowledge / OCR & Chart / Vision-Centric 四轴。
视觉生成DPG、GenEval、短中长 prompt CLIP-Sim、1000 样本 validation diffusion loss；规模实验另报 50k FID。

§ 12误差分析与结论边界：哪些话现在还不能说

单 seed

没有误差条

所有控制实验固定 seed=0，能减少对照噪声，却无法估计结果对初始化和数据顺序的方差。小幅波动不能当稳定差异。

复杂度未量化

七档是探针，不是物理标尺

数据集、语义密度和任务形式一起改变，不能从图中推出严格的 complexity law。

VQA 经过 SFT

测到的是“可恢复能力”

真实数据的 U 分数在 Cambrian-7M 微调后测得，预训练和下游适配的影响没有完全分开。

自动判官

CLEVR 生成误差可能带 judge bias

Qwen3-VL-8B 判 100 张图，未给人工一致性、置信区间或每类错误分解。

静态图像为主

视频、音频、动作仍未验证

时间维会改变 token 成本、记忆和容量竞争，70/25/5 不能直接复制。

5% 的口径

token share ≠ wall-clock compute

生成 loss 乘 3，视觉 token 单位计算量也可能不同。更严谨应说“5% 生成 token 份额”。

Late 配平不可复算

作者给了结论，没给完整排程

论文称 2T late 与 early 看到相同数量的视觉 token，并让 late 到最后 40% 才接入；但未报告最后阶段的 L/U/G 比例或逐步 token 口径。页面因此只把它记为作者声明的控制，不把它当作读者可独立审计的等量实验。

失败不是“生成没学到任何理解知识”

标准 benchmark 上 G→U 没有稳定零样本收益；但 CLEVR 恢复曲线显示，生成确实留下颜色和形状的低层先验。两句话并不矛盾：内部有细节，不代表已经学会把细节映射成 VQA 文字答案。

这篇最硬的贡献是什么

不是 70/25/5 这个具体数字，而是把“统一模型是不是更好”拆成了可复用的实验模板：固定目标数据量测知识流；用可控合成数据区分概念级零样本与潜在先验；把模型 block 拆开定位冲突；用配平 continuation 和内部探针检验训练时机；最后才做规模验证。

拿走一张配方卡先测方向，再分预算；attention 负责交流，FFN 负责分工；视觉别等语言练完才来；少量生成数据可以够用，但不能假装为零，也不能把 token 比例写成算力比例。

REF术语与延伸

  1. Physics of training · 对可重复训练现象的经验刻画，不是已证明的自然定律。
  2. Transfusion / Unified Transformer · 同一 Transformer 对文字做离散 next-token，对图像做连续 diffusion / flow。
  3. RAE · 冻结语义视觉编码器作为 latent，再训练 decoder 还原像素。
  4. 多模态知识流 · 固定目标任务数据，只增加另一任务，观察能力是否转移。
  5. 协同与容量竞争 · 共享表征的收益与有限参数冲突同时存在。
  6. Split FFN / MoT · 按模态拆参数的不同粒度；本篇只拆 FFN，MoT 往往连 attention 也拆。
  7. Catastrophic forgetting · 顺序学新任务时，参数更新覆盖旧任务能力；replay 能缓解但不能重建全程协同。
  8. Vision Laziness · 晚接视觉后，视觉 FFN、wrapper、推理激活和图像注意力一起变弱。
  9. MoE · 总参数很多，每个 token 只激活少数 FFN 专家；本篇 13.5B 总参、约 1.5B active。
  10. 非对称预训练配方 · 先测知识流的边际收益，再决定 L/U/G token 比例。
  11. Early Fusion / Early Unification · 强调模态从训练早期共同塑形；不等同于一定砍掉视觉编码器。
  12. Perplexity · 平均 token 负对数似然取指数，可理解成等效分支数。
