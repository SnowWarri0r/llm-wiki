Addressable memory for video world models

WORLDTRACE.

Xindi Wu · Sven Elflein · James Lucas · Olga Russakovsky · Laura Leal-Taixé · Despoina Paschalidou · Jonathan Lorraine · Aljosa Osep

房间 A 的画面还躺在 KV cache 里，模型却可能已经不会读它。WorldTrace 研究的不是“记忆存没存”，而是“旧记忆还有没有一个 attention 找得到的地址”。

TL;DR

固定 cache 分成久远摘要 + 最近原文。每个摘要槽获得一个训练范围内、互不重合的虚拟时间位置；Field 先去掉旧 RoPE 相位再平均，保连贯；Landmark 冻结场景入口的 canonical Key，保回访。整个方法不改模型权重。

SECTION 00先看结论：保存、寻址、压缩是三件不同的事

玩家从 A 走到 B、C、D，再回到 A。滑动窗口直接删掉 A；完整 KV 虽然保留 A，却要跨越训练时从没见过的超长 RoPE 距离去读它。WorldTrace 的第一判断是：“还在内存”不等于“attention 读得到”。

部署时没有第二个模型。WorldTrace 是 training-free01：冻结原有 world model，只在推理时改变 KV cache02 的读写和 RoPE 地址。也就是说，它同时修复记忆的可寻址性05和写入内容。

SECTION 01先补地基：AR 视频怎样把过去写进 KV cache

Matrix-Game-2（MG2）不是一次生成一分钟，而是每次生成一个 chunk。每个 chunk 有 3 个 latent frame03；下一 chunk 去噪时，当前 Query 去读过去 chunk 留下的 Key / Value。Key 像检索标签，Value 是真正被取回的内容。

训练时，模型只见过有限的 Query–Key 时间距离：

q当前 Query 的绝对时间位置。
k某个缓存 Key 的绝对时间位置。
\delta_{q,k}二者相差多少 latent frame。
\Delta t_{\mathrm{train}}训练见过的最大距离；MG2 为 5。
K检索标签；会被时间 RoPE 旋转。
V被读回的内容；不做 RoPE 旋转。

RoPE04 把每两个 Q/K 维度当成二维箭头，按时间旋转。点积因此带上相对距离。推理若走到 q=30 还想读 k=0，距离 30 远超训练最大值 5：公式当然能算，但模型没学过怎样解释这些相位。

SECTION 02两种失败：旧地址超纲，直接平均又会把内容抵消

地址失败

Block-relative 把所有超长距离截到训练上限。单个旧 token 能回到合法范围；多个摘要槽却会一起撞到最老位置，attention 无法靠位置区分。Centroid-linear 能分开槽，但同一槽随总时长持续漂移，也不符合模型训练过的稳定槽位关系。

内容失败

不同时间的 Key 已被 RoPE 转过不同角度。内容相同的两支箭头也可能朝相反方向；直接平均的是“内容 + 各自旧地址”，不是纯内容。

SECTION 03完整系统：固定七格怎样接住不断增长的历史

SECTION 05P 矩阵不是新网络：它只是写明每个槽抄哪些旧帧

§ 04 解决了摘要槽“放在哪”，这一节回答“槽里的内容怎么来”。论文的做法是先给所有写入策略一个统一记法：不管是 Field 的分组平均、Landmark 的挑帧，还是干脆丢掉旧帧的滑动窗口，本质都是“每个槽按某张配方抄写历史”。把配方写成一个矩阵 P——一行对应一个槽，一列对应一帧历史，行里的数字就是这个槽从各帧抄多少。统一成一个接口，两种 writer 才能在 § 12 用同一套理论分析。

用玩具数字演一遍。六帧历史的 Key 暂时压成标量 K=[2,4,8,10,20,30]^\top——标量没有方向，也就暂时没有 RoPE 相位问题，先把“抄写”这层机制单独隔离出来，相位到 § 06 再回来。预算 4 格：前两格摘要，后两格保留最近原文。

PK 就是普通的矩阵乘法，每行各算一次加权和。拿 Field 的前两行手算：

Field 第 1 行：½×2 + ½×4 + 0×8 + 0×10 + 0×20 + 0×30 = 3（第 1、2 帧的均值）
Field 第 2 行：0×2 + 0×4 + ½×8 + ½×10 + 0×20 + 0×30 = 9（第 3、4 帧的均值）
Landmark 第 1 行：1×2 + 0×… = 2（one-hot 就是“挑中谁抄谁”）
后两行 identity：20、30 原样通过 → PK = [3, 9, 20, 30]ᵀ ✓

这个接口还能写下滑动窗口：所有行都是只指向最近 4 帧的 one-hot，等价于旧帧一列全零、彻底不抄。三种 cache 策略的差别，全部落在这一张矩阵的填法上。

于是完整 attention 和压缩 attention 只差“名单换了”：

\operatorname{softmax}把分数变成非负且和为 1 的权重。
P\in\mathbb R^{L\times T}L 个 cache 槽怎样汇总 T 帧历史。
PK压缩后的检索 Key，L 条。
PV用同一张 P 合并的 Value。
q(PK)^\topQuery 对 L 个槽的原始分数。
\widehat{\mathcal A}固定槽位近似出来的 attention 输出。

两条公式长得几乎一样，唯一的变化是 softmax 面前的候选名单从 T = 6 帧缩成 L = 4 格。注意 P 同时作用在 K 和 V 上：Key 平均了、Value 不按同一分组合并，检索到的地址和取回的内容就对不上了。把玩具数字从头走到尾（配上 V=[10,20,30,40,50,60]^\top、q=.1），看看压缩后的输出离完整版有多远：

完整版（6 条名单）
分数 qK = [.2, .4, .8, 1.0, 2.0, 3.0]
取 exp → [1.221, 1.492, 2.226, 2.718, 7.389, 20.086]，总和 35.13
权重 = [.035, .042, .063, .077, .210, .572]
输出 = Σ 权重×V = 51.0

Field 压缩版（4 条名单）
PK = [3, 9, 20, 30] → 分数 [.3, .9, 2.0, 3.0]
PV = [15, 35, 50, 60]（V 用同一张 P：前两格也是均值）
取 exp → [1.350, 2.460, 7.389, 20.086]，总和 31.28
权重 = [.043, .079, .236, .642]
输出 = 53.7，偏差约 5%

两边最像的地方：真正的大头（最近那帧，分数 3.0）在两个版本里都拿走了最大权重；被平均掉的远处历史只贡献了小头，所以输出只差约 5%。这就是“固定 4 格近似 6 帧”在一次前向里的样子——近似误差集中在被合并的旧帧上，这正是 § 08 讨论两种 writer 取舍的出发点。

两个边界。① NMF 只用于解释，不是推理算法：附录把寻找理想 P 放松成非负矩阵分解08；实际 WorldTrace 不在每轮在线优化 NMF，而是直接用上图两种结构化 P。② P 本身也是分析记法：真实实现不会随历史增长存一个 L×T 矩阵去乘（T 会无限涨），两种 writer 都按 § 06 的方式增量维护等价的槽内容。

SECTION 06Field：先去旧地址，再平均内容，最后写新地址

这条式子只做三步：unrotate → mean → rerotate。中间得到的就是 canonical key06。

f一对二维 RoPE 频率通道。
K^f_{t_m}来源帧 m 在旧时间 t_m 的旋转后 Key。
R(-\theta_ft_m)反向旋转，去掉来源时间相位。
M本槽合并多少帧，由时间分组大小决定。
\frac1M\sum在共同 canonical 坐标系求均值。
R(\theta_ft^v)把纯内容旋到新虚拟地址。

它严格保住的是 pre-softmax 平均分数

取两支 canonical Key：K_1=[1,0]、K_2=[0,1]；Query 为 Q=[2,1]。原分数为 2 和 1，均值 1.5。平均 Key 是 [.5,.5]，点积仍为 2\times.5+1\times.5=1.5。

不能把结论说大。它不保证 softmax 后权重完全一致。softmax09 的每个分母都依赖其他 Key，而且 M 个 token 变成 1 个后，token 数也变了。

主实现并非“总内存严格 O(1)”

recompute writer 把逐出的 canonical Key 留在 CPU host memory，分组边界变动时从来源帧重算，避免“平均的平均”累积误差。GPU attention cache 固定，但 host state 每个 latent frame 增约 5.4 MB。附录的 streaming writer 才只留每槽 sum/count，状态 O(N_s)；N=48 TempSSIM 为 .538，略低于 recompute .545，仍高于滑窗 .472。

SECTION 07Landmark：不是记“平均房间”，而是把入口那一帧原样留下

相邻帧的 canonical Key 做余弦距离10。同一场景内方向接近，距离小；跨入新场景时距离突增，超过阈值 \tau 就记为入口。论文没有公开 τ 数值。

上一帧 a=[1,0]
同房间 b=[.98,.2] → d≈1-.98/1.0002≈.020
新房间 c=[0,1] → d=1-0=1.000
教学阈值 τ=.4 → 只把 c 记成 landmark

摘要槽保存最近 N_s 个入口；装满后新入口淘汰最老者。尚未装满时，空槽重复最老 landmark，避免空内容。

frozen key 每轮都从同一 canonical 原件旋到当前槽位：

t_{\ell^*}选中 landmark 的原始时间。
R(-\theta_ft_{\ell^*})K入口当下只计算一次的 canonical 原件。
t_s^vlandmark 本轮所在摘要槽的虚拟地址。
R(\theta_ft_s^v)从原件新鲜旋到当前地址。
M=1等价于 Field 不平均，只保留一帧。
\mathrm{bf16}反复 unrotate/rerotate 会累积舍入误差，冻结原件可避免。
frozen 不是冻结模型。冻结的是这一个 landmark 的 canonical Key 数值；生成器参数本来就在整个方法中不更新。landmark 仍会因槽位不足被淘汰。

SECTION 08Field 与 Landmark 不是升级关系，而是两种未来查询假设

WorldTrace-Field11

  • 连续时间段做 canonical 平均
  • 适合未来对一段历史分散关注
  • 长处：整体连贯、慢变化
  • 短板：组内某一帧的细节会糊

WorldTrace-Landmark12

  • 场景入口 one-hot 原样保存
  • 适合未来集中找某个旧场景
  • 长处：回访、稀疏事件
  • 短板：漏检或超过槽数就丢

这就是 Field 与 Landmark 的固定预算取舍15。

附录把 4 个摘要槽按 Field / Landmark 混合分配，但中间配比没有单调改善；单 seed 表中全 Landmark 的 recall 最强。论文证明“同一接口能混用”，没有给出自动选择比例的策略。

SECTION 09LoopBench：让模型自己第一次看到的 A，成为回访答案

没有真实游戏引擎 ground truth 时，模型第一次生成的 A 就是参考。走完路线回到几何匹配姿态，再比较返回画面是否复原第一次的 A。这套测试叫 LoopBench14；测的是同一次 rollout 的自洽回访，不是与真实三维世界一致。

TEMPSSIM ↑相邻帧连续吗

相邻解码帧的 SSIM。静止也可能高，不能独自代表世界正确。

LOCAL SCENE DRIFT ↓局部语义漂了吗

相邻 chunk 的 CLIP 特征距离，越低越接近前一段。

PAC ↑回到旧位置像原来吗13

去程与回程匹配姿态的 CLIP-ViT-H/14 余弦相似度。

四个难度轴还包括 90°/180°/360° 原地转镜头和 ABABA/ABCBA/ABCDBA 多次回访。每个条件 100 个不同初始场景；多 seed 为 0、42、123、456、789。

SECTION 12理论部分：证明的是“条件下接近”，不是任意 Query 上最优

这一节回答的是选型问题：固定 L 格预算，哪类 Query 天生适合哪种 P。论文分三步：先把“输出差多少”归结为“分布差多少”，再定义一个理想化的分布匹配目标，最后对两类 Query 各给一条上界——每条上界恰好对应一种 writer。

第一步 · 输出误差被分布失配控制住

Proposition 1（近似界）：压缩前后的输出差，最多是分布失配乘上最大的一行 Value 范数。

r_q(P)压缩 attention 输出减完整输出。
\alpha_q完整 attention 对 T 帧的权重——§ 05 完整版算出的 [.035, .042, .063, .077, .210, .572] 就是一个。
\hat\alpha_q压缩后对 L 格的实际权重，§ 05 里的 [.043, .079, .236, .642]。
\hat\alpha_qP把 L 格权重按配方摊回 T 帧。
\|V\|_{\infty,\mathrm{row}}范数最大的那一行 Value。
意义Value 有界时，只要分布贴得住，输出就差不远——后面只用盯分布。

第二步 · 理想化目标：让槽权重随便配，P 的结构能贴多近

\mathcal Q当前分析的一组 Query。
\gamma_q理论上自由选择的 L 个槽权重。
\gamma_qP把槽权重展开回 T 帧后的近似分布。
\|\cdot\|_1逐位置绝对差相加。
min 算子对每个 Query 选理论最有利的槽权重。
为什么是放松真实推理的槽权重被 \operatorname{softmax}(q(PK)^\top) 锁死，只会更差；J 度量的是 P 结构自身的天花板。

关键是看懂 \gamma_qP。沿用 § 05 的 Field P：\gamma=[g_1,g_2,g_3,g_4] 摊回六帧是 [\tfrac{g_1}2,\tfrac{g_1}2,\tfrac{g_2}2,\tfrac{g_2}2,g_3,g_4]——给合并槽多少权重，就等于把这份权重按配方摊回它的来源帧。结构约束当场浮出来：组内两帧被迫平分，组内不均匀的目标分布怎么配都贴不住。Landmark P 的约束则是：没存下的帧一列全零，那里的目标质量放不进去。

两个 writer 各赢一行、各差一个数量级——§ 08 的取舍在这张表里变成了可以手算的结构事实。

第四步 · 把“适合”写成条件，各给一条上界

Field 的条件（ε-coherent）：归一化的旧史权重距某个“组级均匀混合”的 L1 不超过 \varepsilon_q——即 Query 关心的是时间段而非具体帧。此时 \mathcal J(P_{\mathrm{field}})\le\sum_q\|\alpha_q^{\mathrm{old}}\|_1\varepsilon_q\le\sum_q\varepsilon_q。上面分散型的 \varepsilon_q\approx.097、旧史总质量 .217，上界 .217\times.097\approx.021——和直接算的最优值一致，因为证明用的 γ 就是这么配的：recent 原样复制、旧史按组配比。

Landmark 的条件（δ-covered）：旧史权重距“目标帧的 one-hot”的 L1 不超过 \delta_q，且目标帧已被存为 landmark。此时 \mathcal J(P_{\mathrm{land}})\le\sum_q\|\alpha_q^{\mathrm{old}}\|_1\delta_q。回访型的 \delta_q=.125、旧史质量 .96，上界 .12——成立但不紧（直接最优 .08）。实验用的“最老出局”入口规则，是对这个 δ 覆盖的流式近似，同时相关场景数不超过 N_s 时靠得住。

条件刻画，不是无条件最优。两条上界对各自定义的 Query 族按构造成立，不是对所有 Query 的最优性声明。论文明说没有在预训练模型上实测 ε/δ——量它需要超出训练视野的未压缩 rollout，而 § 01 已经说明那时参考 attention 本身就在退化；条件只能通过它预测的行为（§ 10 的实验）间接检验。

SECTION 13局限：哪类问题它根本没解决

01 · MODEL FAMILY需要 temporal RoPE 的 AR 模型

不是所有双向视频扩散模型都能直接外挂。

02 · FIELD BLUR每槽越压越多

来源数约 T/N_s，具体旧场景会逐渐被平均。

03 · DETECTOR MISS没被选中就无法回忆

τ 未公开，连续转场也未必出现明显峰值。

04 · SLOT CAP最多留 N_s 个场景

进入更多场景后最老 landmark 仍会丢失。

05 · BACKBONE LIMIT不改善物理和动作能力

单 chunk 画质、运动、控制完全继承原模型。

06 · SELF-CONSISTENCYLoopBench 不是真实 3D 验证

参考是模型第一次生成的 A，只证明回访自洽。

最值得迁移的经验：长期记忆 = 有用内容 × 可读地址 × 固定预算下合适粒度。Field / Landmark 决定内容，canonical key 把内容与旧地址拆开，slot-rank 再给它一个模型熟悉的新地址。

术语直达 · 点编号就能看解释

  1. training-free：不再优化生成器权重，只在推理时改 cache 读写；不等于没有超参数或实现工作。
  2. KV cache：保存每层历史 token 的 Key / Value，避免下一步重算。详见概念页。
  3. latent frame：视频经 VAE 压缩后的时空特征帧；MG2 每帧 880 token，不等于一张 352×640 RGB 图直接进入 attention。
  4. temporal RoPE：按时间位置旋转 Q/K，使点积带上相对时间。详见RoPE。
  5. addressability · 可寻址性：记忆不仅存在，而且 Query 能在训练熟悉、彼此可区分的位置上读到。详见概念页。
  6. canonical key：反向旋掉原 RoPE 相位后的纯内容 Key。详见概念页。
  7. virtual position：attention 读取摘要 Key 时临时使用的时间位置；不改来源帧的真实时间与 Value。
  8. NMF：非负矩阵分解，把非负矩阵近似成两个低秩非负矩阵乘积；本论文用于分析理想 P，不是部署算法。
  9. softmax：把一组 logit 变成非负、和为 1 的权重；每项依赖全部分母。详见概念页。
  10. cosine distance：1 减余弦相似度，只比较方向。0 代表同向，1 代表正交，2 代表反向。
  11. WorldTrace-Field：旧历史按连续时间分组，在 canonical 域平均，偏向连贯性。
  12. WorldTrace-Landmark：检测场景入口并原样保留 canonical K/V，偏向具体地点回忆。
  13. PAC：Position-Aligned CLIP，比较去程与回程匹配姿态画面的 CLIP 余弦相似度。
  14. LoopBench：让模型离开 A 并回到 A，以第一次生成的 A 为参考的自洽回访 benchmark。
  15. Field vs Landmark：平滑摘要与关键帧记忆的固定预算取舍。详见概念页。
