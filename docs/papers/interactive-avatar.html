给实时数字人一张参考图，再跟它说“看看手表几点”。它不只要对嘴回答，还得真的抬腕看表；聊久了，手表、衣服和坐姿也不能悄悄漂掉。InteractiveAvatar 用意图状态管动作，用长短期视觉记忆管一致性，再把视频扩散蒸成 3 步流式生成。

Quanyue Song et al. · Xi'an Jiaotong University / TeleAI / Wuhan University · 18 pages including appendix

TL;DR　三条时间线各管一件事：RRM 把每轮对话拆成“动作 → 稳定”状态；短期 memory 密集保存最近 5 秒，长期 memory 只留语义不重复的旧状态；Self-Forcing DMD 把 Wan2.2-5B 改成每块 3 latent、3 个去噪步的流式 student。论文报告 26.68 FPS 与约 2.6 秒首帧等待，但部署流水线使用两张 H100，且没有公开代码、权重或交互人评。

§ 00先纠正六个最容易读错的点

交互

不是“音频来了就动嘴”

ASR 先把用户语音转成文字，LLM 再写动作提示、回答音频和动作结束后的稳定提示。

无限

接口能一直滚，不等于永不忘

两种 memory 都有固定容量。论文明确承认早期状态会被丢掉，物体可能逐渐消失。

实时

不是单卡消费级结果

补充材料的端到端流水线把 DiT 与 VAE 分到两张 H100；主表没有把 26.68 FPS 的 GPU 数说透。

DMD

只负责把步数压下来

DMD04让 3 步生成能实时跑；长期一致性来自 LSVM，动作意图来自 RRM。

KV

不是提示词一换就全清空

只刷新受旧提示影响的相邻生成块；参考块与长短期 memory cache 继续复用。

证据

自动指标不是交互人评

论文量化的是画质、一致性、文字对齐和速度，没有真人对话偏好或动作启动延迟。

§ 01它到底拿来干什么：数字人不能只会“说”

已有流式头像会把回答音频变成口型和粗手势，却很难显式理解“拿书、看表、站起来”这类动作意图；生成时间一长，旧物体和身份细节还会慢慢漂走。

先放回技术演进里Wav2Lip 一类方法先解决“嘴跟声音对上”；扩散头像把画质与全身动作做得更自然；CausVid / Self-Forcing 再把离线多步生成改成能持续往后吐帧；LiveAvatar / StreamAvatar 证明了无限流式头像可行。InteractiveAvatar 接着补两块：让 LLM 明确规划动作，让视觉记忆保留更久以前发生过的事。

§ 03前置一：视频扩散这一块到底在学什么

上一节已经知道 DiT 收到哪些条件。现在先把它的基本训练目标讲清，下一节才看 DMD 如何把几十步压成 3 步。

参考视频帧 x 先经 VAE02 编码为较小的 latent z=E(x)。随机时间步 t 决定保留多少干净信号，标准高斯噪声 \epsilon 补上其余部分：

z_t=\sqrt{\alpha_t}z+\sqrt{1-\alpha_t}\epsilon
z干净视频 latent，张量
z_t时间步 t 的带噪 latent
\alpha_t干净信号保留比例，0 到 1
\epsilon\sim\mathcal N(0,I)与 z 同形的随机高斯噪声

DiT 的输出 \epsilon_\theta(z_t,t,c) 试着还原刚才加进去的噪声；c 汇总文字、音频、参考图和 memory 条件，\theta 是模型参数：

\mathcal L=\mathbb E_{t,z_t,c,\epsilon}\left[\left\|\epsilon_\theta(z_t,t,c)-\epsilon\right\|_2^2\right]

\mathbb E 表示把许多随机 t、视频、条件和噪声样本的损失取平均；\|v\|_2^2 是 L2 范数的平方。向量 v=[v_1,\ldots,v_d] 时，它就等于 v_1^2+\cdots+v_d^2，不再保留开根号。

标量教学例设 z=2、\alpha_t=0.64、\epsilon=-1。
先加噪z_t=\sqrt{0.64}\times2+\sqrt{0.36}\times(-1)=0.8\times2-0.6=1.0。
再比目标若网络预测噪声 -0.7，平方误差是 (-0.7-(-1))^2=0.3^2=0.09。
论文内部口径提醒正文用上面的噪声预测式介绍基础 DiT；后面的 memory 重建式却出现速度式目标。两者没有被作者接起来，§06 会把这个缺口单独留档。

§ 04前置二：DMD 为什么需要 real score 与 fake score

多步 teacher 会去噪，但不够快。DMD 不要求 student 逐步照抄轨迹，而是让 student 生成的一批带噪样本分布靠近 teacher / 数据分布。它最小化反向 KL05：

\mathcal L_{\mathrm{DMD}}=\mathbb E_t\left[D_{\mathrm{KL}}\!\left(p_{\theta,t}\,\|\,p_{\mathrm{data},t}\right)\right]
p_{\theta,t}student 样本加到噪声等级 t 后的分布
p_{\mathrm{data},t}teacher / 真实数据对应的带噪分布
D_{\mathrm{KL}}(p\|q)用 p 的样本衡量 p 与 q 差异
\mathbb E_t对随机噪声等级求平均

score function06 不是“真假分数”，而是对数密度对当前样本的梯度：s(x_t,t)=\nabla_{x_t}\log p_t(x_t)。它和图像 latent 同形，指出朝哪个方向小改，会进入更常见的区域。

\nabla_\theta\mathcal L_{\mathrm{DMD}}=-\mathbb E_{t,z}\left[\left(s_{\mathrm{real}}-s_{\mathrm{fake},\phi}\right)^\top\frac{\partial G_\theta(z)}{\partial\theta}\right]
G_\theta(z)少步 student 生成器
s_{\mathrm{real}}冻结 teacher 给出的目标方向
s_{\mathrm{fake},\phi}用 student 最新样本训练、跟踪其当前分布的 score 网络
\partial G_\theta/\partial\theta把样本空间修改方向传回参数的 Jacobian
(\cdot)^\top转置后做向量内积
\phifake-score 网络参数，与 student 参数 θ 分开
一个标量设 s_{\mathrm{real}}=0.5、s_{\mathrm{fake}}=-0.3、\partial G/\partial\theta=0.4。
梯度g=-(0.5-(-0.3))\times0.4=-0.8\times0.4=-0.32。
更新若 \theta=1、学习率 0.1，则 \theta_{\mathrm{new}}=1-0.1\times(-0.32)=1.032。
两网轮换先用 student 新视频更新 fake-score，使它追上移动中的 student 分布；再冻结两套 score，更新 student。

§ 05长短期视觉记忆：近处保连续，远处保状态

实时视频不能把全部历史一直留在 attention 里。LSVM07把固定预算一分为二：短期池保留最近 5 秒的密集动态，长期池保存更早但语义不同的代表状态。

每个视频 latent z_t 经轻量卷积 + attention 压缩器变成 m_t=\mathcal C(z_t)。时间压缩比为 1，意味着不合并相邻时刻；只把空间网格在高、宽上各再压 4 倍。

\mathcal M_s=\{m_{t-K+1},\ldots,m_t\},\qquad \mathcal M_l=\{\tilde m_1,\ldots,\tilde m_N\}
\mathcal M_s短期 memory 集合
K短期池容量；本文运行点为 30 latent
\mathcal M_l长期 memory 集合
N长期池容量；本文也为 30 latent
\tilde m_i被挑进长期池的第 i 个代表 token 组
t当前视频 latent 序号
VAE 后尺寸1024/16=64，576/16=36。
memory 再压64/4=16，36/4=9，所以每个 memory latent 有 16\times9=144 token。
短期池30\times144=4320 token。
两池合计长期池同容量，因此总 memory 约 4320\times2=8640 token；直播变长也不继续增大。

§ 06memory compressor 怎样学会“压完还能还原”

上一节只规定了 memory 的形状；现在要让压缩 token 真带着有用信息。训练时从一段历史里随机选目标位置，遮掉其余画面，再让 DiT 依靠 long / short memory 重建目标。

目标在短期区

最近画面随机留一部分

目标帧保持干净副本作监督，其余短期帧用噪声遮住，逼 memory 保存局部细节。

目标在长期区

只留时间最近的邻帧当 anchor

anchor 与目标语义相近却不完全相同，迫使长期 token 学场景与物体，而不是逐像素复制。

论文把目标写成下式。H_\Omega 是被抽中的干净目标 latent；\Phi(H) 是两池拼起来的历史；c 是条件；t_i 是各目标的噪声等级：

\mathbb E_{H,\Omega,c,\epsilon,t_i}\left\|\left(\epsilon-H_\Omega\right)-G_\theta\!\left((H_\Omega)_{t_i},t_i,c,\Phi(H)\right)\right\|_2^2
这条式子不能假装完整作者没有定义 (H_\Omega)_{t_i} 的具体插值，正文还把 \epsilon_i\sim\mathcal N(0,I) 误称为“noise levels”。更关键的是，§03 的式 (1) 让网络预测噪声 \epsilon，这里却以 \epsilon-H_\Omega 作目标，更像流速度。能确定的只有“按 memory 重建被遮目标”；不能从本文独立复现这条损失。

§ 07DKFS：不是按时间均匀存，而是挑不重复的旧状态

短期 FIFO08每弹出一个旧 latent，它就成为长期池候选。系统找回对应真实帧，用 SigLIP209抽语义特征并取平均：

\mathbf s_{\mathrm{cand}}=\frac1n\sum_{j=1}^{n}f_{\mathrm{SigLIP2}}(I_j)
I_j候选 latent 对应的第 j 张真实帧
n这组真实帧数量
f_{\mathrm{SigLIP2}}冻结视觉语义编码器
\mathbf s_{\mathrm{cand}}候选的平均语义向量

长期池的冗余度 R 就是所有有序向量对的平均余弦相似度10。候选替换后若 R'<R，整池更不重复，候选才留下：

\cos(\mathbf a,\mathbf b)=\frac{\mathbf a^\top\mathbf b}{\|\mathbf a\|_2\,\|\mathbf b\|_2}

分子是两向量点积，分母把各自长度除掉，所以这里只比较方向是否相近；1 表示同方向，0 表示正交，-1 表示反方向。

\bar\rho_i=\frac1{N-1}\sum_{j\ne i}\cos(\mathbf s_i,\mathbf s_j),\qquad R=\frac1N\sum_{i=1}^{N}\bar\rho_i

§ 08状态循环：回答结束，动作提示也要及时退场

视觉记忆解决“别忘过去”，但不决定“现在做什么”。RRM11把用户文字与上一轮稳定状态交给 LLM，一次产出三样东西：

\left(p_t^{\mathrm{act}},a_t^{\mathrm{resp}},p_t^{\mathrm{stable}}\right)=\operatorname{LLM}\left(x_t,\mathcal S_{t-1}\right)
x_t第 t 轮用户语音的 ASR 文字
\mathcal S_{t-1}上一轮稳定状态；完整字段未公开
p_t^{\mathrm{act}}动作阶段文字提示
a_t^{\mathrm{resp}}回答音频
p_t^{\mathrm{stable}}动作完成后的静态视觉提示
t对话轮次，不是扩散噪声时间步
公式记号又留了空白散文说 LLM 接收“previous stable-state prompt”，公式却写更宽泛的 \mathcal S_{t-1}。它是否包含场景物体、对话摘要或动作历史，论文没有列字段。

§ 09Cache Switching：提示变了，为什么旧邻块 KV 也该刷新

相邻块虽然像素没变，内部 hidden state 却是在旧提示词条件下算出来的。继续复用这些 KV cache12，等于让“坐着聊天”的旧上下文继续拖住“站起来拿书”的新动作。

§ 10四阶段训练：先学会说和动，再学记忆，最后才蒸成实时

前面三套机制现在齐了。训练顺序不能反：一个还不会音频驱动、也不会读 memory 的 student，直接做少步流式蒸馏只会把错误跑得更快。

§ 11数据与系统账：为什么 26.68 FPS 仍要等约 2.6 秒首帧

训练数据≈ 3M

公开头像集 + OpenHumanVid 电影电视 + 私有长对话数据。占比未公开。

训练集群64×H100

Hybrid FSDP15；student LR 1e−5，fake-score LR 2e−6。

推理流水线2×H100

DiT / VAE 分卡，NCCL + NVLink 传特征；WebSocket 推流。

首帧等待≈ 2.6s

生成速度超过播放速度，不等于用户开口后立刻看到第一帧。

首帧 2.6 秒逐项对账

DiT约 450 ms。
轻量 VAE约 50 ms。
LLM / 音频回答约 1600 ms，占 2.6 秒约 1600/2600\approx61.5\%。
其他开销约 450 ms；合计 450+50+1600+450=2550 ms，四舍五入约 2.6 秒。

数据过滤先算美学分、切镜头，再做人脸检测和唇音同步检查。Gemini 从视频里找动作事件：事件开头标 action prompt，结尾标 stable prompt。这一步为状态循环制造监督，但过滤阈值、模型版本与人工复核比例都没公开。

§ 12主结果：它赢在一致性与速度，不是所有画质指标

500 个测试视频覆盖短、长和多次动作切换。主表在 H100 上比较 8 种方法，但没有说明 26.68 FPS 是否采用补充材料的双卡流水线。

画质

IQA / ASE 分别估计感知质量与审美；越高越好。FID 比较单帧分布，FVD 比较视频时空分布；越低越好。

口型

SynC 是唇音同步置信度，越高越好；SynD 是唇音特征距离，越低越好。

一致性

OBJ 由 Gemini 判断物体跨帧是否稳定；ID 用 DINOv3 比较全身、衣服与身份，越高越好。

听指令 / 速度

TV 用 VideoCLIP 衡量视频和动作文字是否对齐；FPS 是每秒生成帧数。

§ 14我的判断：系统思路完整，复现证据仍缺关键几块

真正站得住的

三种时间尺度分工清楚

LLM 管一轮交互状态，短期池管相邻画面，长期池管远期物体；DMD 另管速度。消融基本支持这四笔账。

仍然站不住的

“像真人交流”证据不足

没有动作启动延迟、人类偏好、多轮成功率或小时级压力测试；自动指标只能证明更听提示、更稳，不能证明交流自然。

论文自己承认的失败

固定 memory 会丢早期 latent；长视频和大动作可能退化；曾经出现的物体会逐渐消失；首帧没有的新物体在提示词提到后可能突然冒出来。Prompt 可以缓和，但不能根治。

论文没有告诉我们的事

代码与权重、完整 RRM prompt、状态容器字段、memory compressor 结构、DKFS 槽位选择伪代码、数据配比与过滤阈值、26.68 FPS 的准确 GPU 数与显存、最长稳定时长，以及 cache switching 单项节省的毫秒都没有公开。

一句带走InteractiveAvatar 最值得记的不是“又一个实时头像”，而是把该做什么、刚做过什么、很久以前发生过什么分给三套状态管理，再让少步视频生成器只负责把这份状态演出来。

术语直接可达

  1. ASR · Automatic Speech Recognition，把用户语音转成文字；RRM 读的是文字意图，不直接从波形推理动作。
  2. VAE / video latent · 把像素视频压进更小的连续张量，DiT 在 latent 中去噪，最后再解码回帧。
  3. 因果 attention · 当前块能看过去、不能看未来；保证直播时不偷看尚未发生的画面。
  4. DMD · Distribution Matching Distillation，用 real / fake score 的差把多步扩散蒸成少步生成器。详见 概念页。
  5. Reverse KL · 用 student 分布自身的样本衡量它离目标分布多远；DMD 的分布目标。
  6. Score function · \nabla_x\log p(x)，与样本同形的修改方向，不是 0 到 1 的真假评分。详见 概念页。
  7. LSVM · Long-Short Visual Memory，短期密集、长期稀疏的固定容量历史。详见 概念页。
  8. FIFO · First In First Out，先进先出队列；短期池满时，最早进入的 latent 先弹出。
  9. SigLIP2 · 视觉语言编码器，把真实帧变成语义向量；本文用它判断关键帧内容是否重复。
  10. 余弦相似度 · 点积除以两向量长度，只比较方向；越接近 1 表示语义向量越像。详见 点积页。
  11. RRM · Reasoning-Reaction Module，LLM + 音频回答系统；把用户意图变成动作、回答与稳定提示。
  12. KV cache · 保存 attention 已算过的 Key / Value，后续块无需重算；提示变更后需判断缓存条件是否仍有效。详见 概念页。
  13. Wav2Vec · 语音表征编码器，把波形变成按时间排列的声学特征，再通过 cross-attention 控制口型。
  14. Block-causal attention · 块内可并行互看，块间只看过去；兼顾视频块并行与流式因果。详见 概念页。
  15. Hybrid FSDP · 在部分 GPU 间分片参数、梯度和优化器状态，在另一层组间复制，平衡显存与通信。详见 概念页。
