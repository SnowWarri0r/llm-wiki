2026-09-09paperTaoMate · 让实时数字人既记得刚才，也不忘最初是谁TaoMate 把历史拆成三份：首段参考永远保留、最近两块留在带位置的 KV cache、更早内容压成固定大小的音视频记忆；每个干净块生成后再用“旧记忆 + 新观察 + 首段锚点”更新长期状态，并把三个去噪阶段做成跨块流水线。 2026-09-09concept锚点牵引的持久记忆 · 能更新，但每次都回看原始参考把旧记忆、新观察和固定参考做加权平均；新内容能进入记忆，偶发错误会淡出，固定参考则在每次更新时重新加入，阻止身份长期漂走。 2026-09-09conceptReference-aware FiLM · 用一组全局旋钮校准颜色和亮度内容记忆回答“当前 token 应该找哪段历史”，适合 attention；通道均值、对数标准差等外观统计要同时影响所有视频 token，适合用 FiLM 生成逐通道缩放和偏移。 2026-09-09conceptRollout-aligned causal-context distillation · 用部署时会遇到的历史出题老师能看干净双向轨迹，线上学生却只能接着自己的旧输出继续生成；训练因此混入不同长度的自回归 rollout、学生生成前缀和轻度受损历史，让学生提前见到部署时的输入分布。 2026-09-09conceptStage-parallel denoising · 不同视频块同时站在不同去噪工位把少步去噪的每一步分给一个设备；块 0 做第二步时，块 1 可以同时做第一步，填满流水线后每个节拍都能产出一个干净块。 2026-08-24paperControlNet · 文字管“画什么”，条件图管“画在哪”冻结原 Stable Diffusion，只复制 U-Net 的 12 个编码块与中间块来学空间条件；零初始化的 1×1 卷积保证训练刚开始时旁路修正严格为零。 2026-08-24conceptClassifier-Free Guidance · CFG让模型同一步算两遍 —— 一遍看着 prompt、一遍蒙着眼，再把"看着 prompt 多走的那部分"放大，逼它更听话。 2026-08-24conceptConvolution · 卷积 · 一把小尺子滑过整张图拿一个小窗口（卷积核）滑过整张图，每停一处就把窗口盖住的像素跟核逐元素相乘再求和得到一个数 —— 滑遍全图得到一张新图（feature map）。 2026-08-24conceptCross-Attention · 交叉注意力Decoder 用自己的 Query，去查 Encoder 输出的 Key/Value，让生成过程能看见输入序列。 2026-08-24conceptFrozen Backbone + Side Network · 主干保能力，旁路学增量冻结已经训练好的主网络，只让旁路学习新任务需要的修正。 2026-08-24conceptNoise Prediction Objective · 让网络猜“刚才加进去的噪声”训练时自己往干净样本里加一份已知高斯噪声，再让网络把这份噪声猜回来；因为标签是自己造的，不需要人工标注。 2026-08-24conceptPretrain-Finetune Paradigm · 先预训练再微调先在<strong>无标注</strong>大语料上用自监督任务（MLM / LM）预训练一个 transformer，再在每个下游任务的<strong>小标注集</strong>上 finetune —— 一个 backbone 万能。 2026-08-24conceptSemantic Segmentation · 语义分割 · 给每个像素分类分类只给整张图一个答案；语义分割给图里的每个像素一个类别，最后输出一张与图像逐点对应的 mask。 2026-08-24conceptSpatial Conditioning · 用一张图直接指定“哪里该长什么结构”文字给语义，空间条件图给每个位置的结构约束。
