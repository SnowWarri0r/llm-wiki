2026-08-11conceptCanonical RoPE Keys · 去掉位置旋转的 KeyCanonical Key 是把 RoPE 已写入 Key 的旧位置相位反向旋掉后，留下的内容坐标；要合并不同时间的 Key 或给它们换虚拟位置，应先回到这个共同坐标系。 2026-08-11conceptField vs Landmark Memory ·
