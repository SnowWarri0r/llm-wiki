Concept

Swap-and-Reconstruct Supervision · 把真片改坏，再让模型恢复

一句话

真实片始终当干净标签；人工改身份只负责制造输入，从而绕开难收集的跨身份逐帧配对。

直觉

要训练“把甲的动作换成乙的外观和声音”，理想数据得让甲和乙说同一句话、做同一动作、处在同一背景，而且每一帧都对齐。这种数据几乎不存在。

Swap-and-reconstruct 换个问法：从乙的真实视频出发，先把乙的身份线索拿掉或换乱，再把乙的一张照片和一段声音交给模型，让它恢复原视频。答案仍是现实里拍到的真片，不是旧模型生成的伪标签。

怎么做的

以 UniSwap 为例：

真实目标：乙的视频 + 乙的声音
  ├─ 人物分割后换成姿态骨架 → 保动作 / 背景，弱化外观
  ├─ 变声到随机说话人       → 保台词 / 韵律，打乱音色
  ├─ 抽乙的一帧             → 参考外观
  └─ 抽乙声音全长的 30%     → 参考音色

模型输入：退化源视频 + 变声源音频 + 参考图 + 参考声音
训练目标：恢复原始真实视频和真实声音

数字例子

一条训练片长 10 秒：参考音频取 30%，就是 3 秒。余下 7 秒的原音色不能从参考音频逐采样复制，模型必须把这 3 秒里提取到的说话人音色，迁移到整段源台词。

视频侧若每秒 25 帧，10 秒约 250 帧；参考图只有 1 帧。模型不能把这一帧当动画逐帧复印，必须结合姿态源恢复另外约 249 帧的动作与视角。

自检：参考只提供“是谁”，源只提供“说什么、怎么动、背景是什么”，两边信息合起来才足以重建目标。

边界

  • 人工退化若没把身份拿干净，模型可能走捷径，直接从源里抄脸或音色。
  • 退化器的伪影可能成为训练域特征；部署输入若来自真实的另一身份，分布并不完全相同。
  • “标签是真实片”不等于全部输入都是真实分布；姿态渲染和变声音频仍是人工构造。
