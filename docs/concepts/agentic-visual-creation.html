Concept

Agentic Visual Creation · agent 搭台，扩散唱戏

一句话

让 agent 写代码造出显式可控的场景（参考图、可编辑 3D、可执行游戏），再让视频扩散模型往上面渲染细节。

直觉

视频扩散和 agent 造景各缺半边：扩散画得漂亮但随机难控（精确内容靠反复抽卡、长镜头会漂），agent 写出来的 3D 场景和游戏控制精确可重放，但低模贴图糙、离"能看"差得远。把两者拼起来正好互补——几何、运动、碰撞由程序说了算（可检查、可回放、可改参数），外观交给扩散模型补。相当于剧组分工：agent 是置景和场记，扩散模型是摄影和调色。

怎么做的（LynnReal-Omni 的版本）

  • 场景构建：agent 读参考图和任务描述，用网格/层级/变换/材质/光照/相机写出可执行场景，先搭主结构再精修，靠执行反馈抓实现错误。
  • 位姿与相机精修：从参考视角渲染、和输入图比构图/剪影/透视/遮挡，每次更新都重渲验证；先整体视角后局部比例，防"局部几何迁就错误透视"。
  • 接触校正与验证：多视角渲染暴露隐藏几何与穿插；碰撞检测定位缝隙和重叠；改完复查邻近物体。
  • 游戏逻辑：显式状态更新（位置/速度/朝向/动作相位）+ 控制输入；录制脚本按固定输出时间间隔推进仿真逐帧截图，状态与交互事件随帧存档——录制耗时与播放速度解耦。
  • 渲染出的序列作为布局/运动参考喂给视频模型（帧对齐控制），程序本体保留，随时改参数重渲。
