Concept

Time-Align RoPE · 让两路视频的同一时刻拿到同一时间地址

一句话

目标第 t 帧与参考第 t 帧共享时间坐标，但空间地址错开，既能对齐动作又不会把两个位置误认成同一 token。

直觉

把 RoPE 地址想成“时间 + 座位号”。两段视频里同一时刻的人应该拿同一个时间戳；但目标画面和参考画面毕竟是两张不同的图，所以座位号不能重合。Time-Align RoPE 同时满足这两件事。

怎么做的

普通做法可能先排完整段目标，再排完整段参考，于是参考的第一帧会被编码成“目标最后一帧之后”。Wan-Animate 2 改成按帧对齐理解：时间维都使用 t，参考分支的空间坐标再加一个偏移量。

数字例子

设目标每帧有 4 个空间 token，参考每帧有 2 个，时间只有 t=0,1：

token 时间坐标 空间坐标
目标帧 0 0 0,1,2,3
参考帧 0 0 4,5
目标帧 1 1 0,1,2,3
参考帧 1 1 4,5

目标帧 1 与参考帧 1 都带时间坐标 1，因此“同时发生”；空间坐标分别是 0…3 与 4…5，所以又不会地址冲突。这里的数字只是教学例，论文实现把这一思想编码进三维 RoPE。

它替代了什么

它替代“把两段视频首尾拼接后统一编号”的简单做法。后者把参考帧推到错误的时间位置，会让 attention 先克服位置偏差，才有机会学到动作对应关系。
