Concept

未来参与分数 · 按"后面还剩多少"给每块损失加权

一句话

自回归序列里前面的块历史少、后面的块历史多且要压住误差累积；用"块 j 及之后的元素占比"当坐标，套一个权重函数决定谁的损失更重，再归一化让平均权重不变。

直觉

改一篇连载小说，第一章没有前文包袱、最后一章要兜住所有伏笔。给每章的修改意见按"它后面还有多少章"排轻重：想让作者重视收尾，就把权重压到后面几章；想让开头打好底，就压到前面。RAVEN 的结论是压到后面（α=−1）最好——后面的块才是"接龙接得稳不稳"真正考验的地方。

怎么做的

J 块，块 j 有 m_j 个标量、损失和 ℓ_j
p_j = Σ_{k≥j} m_k / Σ_k m_k        # 未来参与分数：块 j 及之后占总元素的比例
w̃ = g_η(p_1..p_J)                  # 权重函数，输出非负原始权重
w_j = w̃_j · Σ_k m_k / Σ_k w̃_k m_k   # 归一化：元素平均权重 = 1
L_chunk = Σ_j w_j ℓ_j / Σ_j w_j m_j

p_j 前面大（p_1=1）后面小，单调递减。g_\eta 只管相对分配，归一化保证总梯度尺度不因 g_\eta 变化。

RAVEN 试的 g_\eta：SD3 的 mode 密度（s=−0.54 / 0.81）、logit-normal (0,1)（都对每块覆盖的区间积分），以及 shift 家族

π_α(p) = α p / (1 + (α−1) p)
α=1  → π=p，偏早块
α=0  → 论文称"均匀"（字面公式退化为 0，只能当约定读）
α<0  → 把 π_|α| 套在反向坐标 p_J / p_j 上，偏晚块

数字例子

J=4，每块 m=1，p=(1,.75,.5,.25)。

α=1：原始权重就是 p = (1, .75, .5, .25)；归一化因子 4/2.5=1.6 → w=(1.6,1.2,.8,.4)，平均 1 ✓。

α=−1：反向坐标 p_4/p_j=(.25,.333,.5,1)，套 π_1 不变；归一化因子 4/2.0833=1.92 → w=(.48,.64,.96,1.92)，平均 1 ✓。最后一块权重是第一块的 4 倍。

套一组损失 \ell=(.4,.3,.5,.6)：均匀平均 0.45；α=−1 得 (.48×.4 + .64×.3 + .96×.5 + 1.92×.6)/4 = 0.504——后面块的 .5 和 .6 被放大了。

块大小不等时 p 跟着变：m=(2,1,1,1) → p=(1,.6,.4,.2)，第一块因为自己占 2/5 而把后面的起点压到 .6。
