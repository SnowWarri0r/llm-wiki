Concept

Per-frame 3D Memory · 每帧各存一份几何，只拿它找路

一句话

不把所有历史深度硬融合成一张全局点云；每帧独立保存深度、相机和稀疏点云，生成新视角时再挑出当前真正看得见的几帧。

为什么不直接融合

估计深度不是精确测量。假设同一墙角在帧 A 被估到 4.9 m，在帧 B 被估到 5.2 m；融合后会留下两层互相打架的墙。若把这张点云渲染成下一轮 RGB 条件，错误会进入生成结果，再被估深度、继续融合，形成闭环放大。

逐帧缓存保留“谁看见了什么”的来源。目标相机到来时，系统把每帧的低分辨率点云投影到目标平面，处理遮挡后数可见点；再选覆盖最多尚未覆盖像素的帧。选中的原始旧帧供视频模型读取，几何本身只负责路由和坐标对应。

这不是零误差方案：可见性和对应仍依赖估计深度。优点只是不把局部误差提前焊成不可撤销的全局外观。
