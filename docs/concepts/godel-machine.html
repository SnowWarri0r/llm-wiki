Concept

哥德尔机 · 证明了才准改自己

一句话

Schmidhuber 2007 年的理论构想：一个 AI 只有在能形式化证明某次自我修改净有益时，才执行这次修改。

直觉

把"自我改进"想成给自己做手术：哥德尔机的立场是"没有手术成功的数学证明,不许动刀"——绝对安全,但也几乎绝对不动刀。实践中,"这次修改是否有益"依赖模型训练历史和任务上下文(给 coding agent 加个测试工具听起来必好,实际可能把它搞糊涂),根本无法事先证明。于是这个构想停在纸面近二十年。

怎么做的(以及为什么做不成)

  • 系统携带一个定理证明器,搜索"改写自身代码 + 该改写可证有益"的组合;
  • 卡点:除非对系统做强假设,绝大多数修改的净收益不可证;
  • dgm 的放松:把"证明有益"换成"实测有益"——修改先做出来,拿基准考试,分数说话。这正是达尔文进化的逻辑:突变不预先验证,生成、试炼、选择。
