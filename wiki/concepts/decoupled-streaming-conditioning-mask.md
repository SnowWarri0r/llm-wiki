# Decoupled Streaming Conditioning Mask · 条件各自编码，当前块只看该看的

## 一句话

把参考、源块、历史和当前目标分成不同角色，训练时就按推理时的可见范围挡住未来。

## 直觉

离线模型像拿到整部电影后补第 20 秒：它能偷看第 21 秒。流式模型到了第 20 秒，手里只有参考身份、原视频当前片段和自己已经生成的过去。训练若不堵住未来，模型会学会依赖部署时拿不到的信息。

“Decoupled” 指不同区域按职责使用不同可见规则，不是整张注意力矩阵只套一个普通下三角。

## 怎么做的

生成第 \(i\) 个目标块 \(B_i\) 时：

\[
B_i\leftarrow f(\mathrm{ref},S_i,B_{<i}^{\mathrm{clean}},B_i^{\mathrm{noisy}}).
\]

- \(\mathrm{ref}\)：永久参考图与参考声音；
- \(S_i\)：时间上与当前目标对齐的源视频/音频块；
- \(B_{<i}^{\mathrm{clean}}\)：已经完成的目标历史；
- \(B_i^{\mathrm{noisy}}\)：本轮正在去噪的当前块；
- 未来目标块 \(B_{>i}\)：不可见。

参考和各源块独立编码，防止它们相互偷传未来；目标历史按块因果读取。视频 self-attention、音频 self-attention 和双向 cross-attention 都套相同的角色规则，但各模态用能覆盖同一真实时段的块长。

## 数字例子

假设有四个目标块 \(B_0,B_1,B_2,B_3\)，现在生成 \(B_2\)：

| 区域 | 能否看见 | 原因 |
|---|---:|---|
| 参考身份 | 是 | 整段都要保持同一个人和声音 |
| 源块 \(S_2\) | 是 | 提供这一秒的动作与台词 |
| 历史 \(B_0,B_1\) | 是 | 保持生成连续 |
| 当前 \(B_2\) | 是 | 去噪必须在块内互相计算 |
| 未来 \(B_3\) | 否 | 流式推理时还不存在 |
| 源块 \(S_3\) | 否 | 防止提前读取未来源内容 |

若把 \(B_3\) 放开，训练损失可能更低，但部署时这条信息突然消失，等于考试前一直看答案、考试时才收走。

## 跟普通 causal mask 的区别

普通 token-causal mask 要求每个 token 只能看更早 token。这里当前块内部允许双向注意力，因为一次要共同去噪整块；因果边界落在“块与块之间”，同时还要处理参考和对齐源块两种非生成条件。
