# Sparse Reference Attention · 每帧只查对应时刻的参考帧

## 一句话

目标视频内部仍可全局互看，但目标第 \(t\) 帧只读取参考第 \(t\) 帧。

## 直觉

如果在学“第 2 秒抬手”，没有必要让目标第 2 秒同时查询参考视频第 0、1、2、3 秒的全部像素。先用时间对齐把正确参考帧找出来，再只在这一帧里挑细节。

## 怎么做的

设每段有 \(T\) 帧，目标每帧 \(S_t\) 个 token，参考每帧 \(S_r\) 个 token：

\[
\text{全量跨分支连边}=T^2 S_t S_r
\]

\[
\text{按时间对齐连边}=T S_t S_r
\]

注意：被裁掉的是“目标查询参考”的跨分支连边；目标分支的自注意力仍保持完整。

## 数字例子

取 \(T=3\)、\(S_t=4\)、\(S_r=2\)：

- 全量比较：目标共有 \(3\times4=12\) 个 query，参考共有 \(3\times2=6\) 个 K/V，连边数为 \(12\times6=72\)。
- 时间对齐：每个时刻只有 \(4\times2=8\) 条跨分支连边，三个时刻共 \(3\times8=24\)。
- 这组小例子把跨分支比较量从 72 降到 24，正好减少 3 倍；一般会减少约 \(T\) 倍。

论文把复杂度写成从 \(\mathcal{O}(N_r N_l)\) 降到 \(\mathcal{O}(N_l)\)，隐含前提是每帧参考 token 数视作固定常数。若把 \(S_r\) 也展开，更完整的写法是上面的 \(\mathcal{O}(T S_t S_r)\)。
