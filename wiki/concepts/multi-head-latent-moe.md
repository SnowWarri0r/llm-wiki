# Multi-Head LatentMoE · 把一个 token 切成小头，每个头自己挑专家

## 一句话

不让整个 token 去选专家，而是先把它切成若干低维子向量，每个子向量有自己的路由器和专家池，各选各的再拼回来。

## 直觉

普通 MoE 像医院分诊：一个病人（token）整体被分到 2 个科室（专家），每个科室看完整的病人。多头 MoE 像体检中心：病人的血、眼、心电图这些"子项"各自排队，每一项都有自己那一层的一排小窗口，各挑最合适的几个窗口办完再汇总成一份报告。

好处有两条：

1. **组合更多**：同一个 token 的不同子空间可以落到不同专家组合上。MAGI-2 每层 12 个头 × 256 个专家，一个头 top-6 就有 \(C(256,6)\approx 3.7\times10^{11}\) 种选法，12 个头各选各的。
2. **通信形状固定**：切分是按维度切的，每个头整块交给负责它的那张卡——发多少、收多少在开训前就算得出来，不随当前 batch 的路由结果抖动（见 [[head-parallel]]）。

代价：每个专家只看 256 维的子空间，单个专家的"视野"窄了。和"整 token 路由的宽专家"相比效果差多少，MAGI-2 没给消融。

## 怎么做的

\[ \tilde x = W_{\mathrm{in}}x,\qquad \tilde x\to[x^{(1)},\dots,x^{(M)}],\qquad x^{(h)}\in\mathbb R^{H_{\mathrm{head}}} \]

\[ I^{(h)}=\mathrm{TopK}_k\bigl(\sigma(G^{(h)}x^{(h)})+b^{(h)}\bigr),\qquad y^{(h)}=\sum_{e\in I^{(h)}}p^{(h)}_e\,E^{(h)}_e(x^{(h)}) \]

\[ y=W_{\mathrm{out}}\,\mathrm{Concat}(y^{(1)},\dots,y^{(M)}) \]

- \(W_{\mathrm{in}}\) / \(W_{\mathrm{out}}\)：split / merge 投影，把隐状态映射进、映射出"路由表示"。
- \(G^{(h)}\)：第 h 个头自己的路由矩阵（256 个专家 × 256 维），打出 256 个分数。
- \(\sigma\)：sigmoid，把每个分数压到 0–1，专家之间互不竞争（不是 softmax）。
- \(b^{(h)}\)：负载均衡偏置，只影响"选谁"（见 [[aux-loss-free-load-balancing]]）。
- \(p^{(h)}_e\)：被选中专家的权重——用**不带偏置**的 sigmoid 分数在选中的 k 个里归一化，MAGI-2 再乘常数 4.9。
- \(E^{(h)}_e\)：一个 256 → 1,280 → 256 的 SwiGLU7 小 FFN。

MAGI-2 配置：宽 3,072，M=12 个头、每头 256 维，每头 256 个专家、top-6。推理代码里 MoE 层还并联一个所有 token 都走的共享专家和一个按模态区分的共享专家；博客公式把 \(b\) 写在 \(\sigma\) 括号里，代码是在 \(\sigma\) 之后加、且只用于选择。

## 数字例子

一个头、4 个专家、top-2（真实是 256 选 6，算法一样）。

1. 路由打分 \(G^{(h)}x^{(h)}=(1.2,\ 0.4,\ 0.9,\ -0.5)\)。
2. 过 sigmoid：\(\sigma(1.2)=0.769\)，\(\sigma(0.4)=0.599\)，\(\sigma(0.9)=0.711\)，\(\sigma(-0.5)=0.378\)。
3. 加偏置 \(b=(-0.2,\ +0.1,\ 0,\ 0)\)（专家 1 最近太忙被压低、专家 2 太闲被抬高）：\((0.569,\ 0.699,\ 0.711,\ 0.378)\)。top-2 = 专家 3、专家 2。不加偏置时会选专家 1、3。
4. 权重用**原始** sigmoid 分数在选中者里归一化：\(0.711/(0.711+0.599)=0.543\)，\(0.599/1.310=0.457\)，加起来 1 ✓。
5. 乘路由缩放 4.9：\(2.66,\ 2.24\)。输出 \(y^{(h)}=2.66\,E_3(x^{(h)})+2.24\,E_2(x^{(h)})\)。

**规模账**：每层 12×256 = 3,072 个专家单元，每 token 激活 12×6 = 72 个。一个专家 \(256\times1280\times2+1280\times256=983{,}040\) 个参数；一层激活的路由专家 \(72\times983{,}040\approx70.8\)M，36 层 ≈ 2.55B——只占 MAGI-2 约 5.92B 激活参数的 43%。

## 跟普通 MoE 的对照

| | token-choice MoE | Multi-Head LatentMoE |
|---|---|---|
| 谁去选专家 | 整个 token（H 维） | 每个头的子向量（H/M 维） |
| 专家宽度 | 宽（输入 H 维） | 窄（输入 H/M 维） |
| 跨卡通信 | ∝ N·k·H，形状随路由变 | ∝ N·H，形状按头静态确定 |
| 组合方式 | 每 token 一组 k 个 | 每 token M 组、每组 k 个 |
