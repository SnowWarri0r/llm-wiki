# Vision Laziness · 视觉惰性 · 图在眼前，模型却更愿意靠文字猜

## 一句话

如果语言主干先练得很成熟，再把视觉接进来，优化器容易沿用现成的语言捷径：视觉分支虽然存在，激活更弱、被注意得更少，最终没有学成与语言平级的能力。

## 生活直觉

一道带图选择题里，题干出现“沙漠动物”，模型不看图片也能猜骆驼。这个捷径短期能降低损失；但它让“认真读取图中究竟是什么”得到的梯度更少。久而久之，视觉模块像公司里总被老员工代做工作的新人：在岗，却一直没有真正承担任务。

## 论文不是只看最终分数

它给不同成熟度的语言 checkpoint 同样的 200B 联合训练，再从四个角度检查视觉到底有没有被使用：

1. 训练时图像 FFN 输出的 L2 范数；
2. 图像起止标记 embedding 的 L2 范数；
3. 真正推理时图像 FFN 的逐元素 RMS；
4. 注意力落到图像 token 上的比例。

四项都随语言预训练起点从 0B 推迟到 800B 而下降，才构成“视觉惰性”的内部证据链。

## L2 和 RMS 到底在量什么

给激活向量 $h=(h_1,\ldots,h_n)$：

\[
\lVert h\rVert_2=\sqrt{\sum_{i=1}^{n}h_i^2},\qquad
\operatorname{RMS}(h)=\frac{\lVert h\rVert_2}{\sqrt n}.
\]

例如 $h=[3,4,0,0]$，L2 是 $5$，RMS 是 $5/\sqrt4=2.5$。L2 会随张量元素数量变大；除以 $\sqrt n$ 后得到平均每个元素的典型幅度，才适合比较形状不同的激活。

数值变小不自动等于能力差；但当训练激活、推理激活、wrapper embedding、图像注意力和最终视觉指标一起下降时，解释就更可信。

## 边界

“惰性”是这篇论文给一组相关内部现象起的名字，不是已经证明的普遍定律。不同架构、数据规模和更强视觉监督下是否仍成立，还需要重复实验。
