# 一致性采样步当策略 · CM-GRPO 不借 SDE 也能做在线 RL

## 一句话

一致性采样每步是"预测干净端点、再按目标噪声级重新加噪"，本身就是一个高斯转移；直接把它当策略算 log 概率做 GRPO，不必像 Flow-GRPO 那样把 ODE 改成 SDE 再离散化。

## 直觉

做 RL 要有"策略的概率"，确定性 ODE 采样器没有概率可言（同一输入永远同一输出）。Flow-GRPO 的办法是训练时人为加噪：把 ODE 换成同边缘分布的 SDE，Euler-Maruyama 一步就是高斯核，比率和 KL 都能写出来——代价是这些随机转移推理时根本不用，训练在优化一个推理时不存在的过程。

一致性采样器（少步蒸馏模型常用）不需要这套：每步先猜干净图 \(\hat x_\theta\)，再按下一噪声级 `s` 加噪 \(\hat z^{(s)}=\alpha_s\hat x_\theta+\sigma_s\epsilon\)。那个 ε 是推理本来就有的随机性，所以策略核 = 推理核，训练和推理走的是同一条转移。

## 怎么做的

```
一步 u → s：
  x̂_θ = f_θ(ẑ^(u), u, c)                      # 预测干净端点
  ẑ^(s) = α_s x̂_θ + σ_s ε,  ε~N(0,I)           # 推理本来就这么采
  ⇒ π_θ(ẑ^(s) | ẑ^(u), c) = N(α_s x̂_θ, σ_s² I)   # 策略核，均值 μ = α_s x̂_θ

GRPO：同一 c 采 G 条轨迹，端点打分 R_i
  Â_i = (R_i − mean R) / (std R + ε)，广播到该轨迹上的每个转移
  log π = −‖ẑ^(s) − μ‖² / (2σ_s²)（去掉常数）
  ∂(−Â log π)/∂x̂_θ = −Â α_s (ẑ^(s) − μ) / σ_s²

实现：stop-gradient 回归
  L = ‖ x̂_θ − sg( x̂_θ + Â α_s/(2σ_s²) · (ẑ^(s) − μ) ) ‖²
  对 x̂_θ 求导恰是上面的梯度（与 DMD 的 score 梯度回归同一个模子）

参考 KL（闭式，RAVEN 没用）：
  KL(π_θ ‖ π_ref) = α_s² ‖x̂_θ − x̂_ref‖² / (2σ_s²)
```

读法：优势为正时，把 \(\hat x_\theta\) 往"使那次采样更可能"的方向推——采到的 `ẑ^(s)` 比均值高，就抬高 \(\hat x_\theta\)；优势为负反向。最后一步 \(\tau_K=0\) 时 \(\sigma=0\)，核塌成 Dirac、log 概率没定义，所以只在前 K−1 个转移上采。

## 数字例子（标量）

\(\alpha_s=0.6,\ \sigma_s=0.8\)，模型预测 \(\hat x_\theta=2.0\) → 均值 \(\mu=1.2\)；采样 ε=0.5 → \(\hat z^{(s)}=1.2+0.8\times0.5=1.6\)。

- log π = −(1.6−1.2)²/(2×0.64) = −0.125
- 优势 Â=+1：梯度 = −1×0.6×0.4/0.64 = **−0.375**（负梯度 ⇒ 沿梯度下降会把 x̂_θ 抬高——采到的比均值高，鼓励往高处走）
- 回归目标 = 2.0 + 0.6/(2×0.64)×0.4 = 2.0 + 0.1875 = 2.1875；\(L=(\hat x_\theta-2.1875)^2\) 对 x̂_θ 求导 = 2×(2.0−2.1875) = **−0.375** ✓ 两条路一致
- Â=−1：目标变 1.8125，把 x̂_θ 往下压
- 若参考模型给 x̂_ref=1.5：KL = 0.36×0.25/1.28 = 0.0703

对照 Flow-GRPO 的 EM 核（τ=0.5, σ=0.4, y=1, v=−1）：漂移 \(b=v+\tfrac{\sigma^2}{2\tau}(y+(1-\tau)v)=-1+0.16\times0.5=-0.92\)，Δτ=0.25 一步后均值 0.77、噪声标准差 σ√Δτ=0.2——这 0.2 的噪声是训练时加的，推理 ODE 里没有。

## 消融（RAVEN 表 4，同起点同奖励）

EM 核 σ∈{.1,.4,.8} × KL 权重 β∈{0,.004} 六格总分 85.03–85.27；CM-GRPO 85.46。作者的结论：策略核一旦和推理采样器一致，辅助随机过程就没必要，也省掉 σ、β 两个要联调的旋钮。
