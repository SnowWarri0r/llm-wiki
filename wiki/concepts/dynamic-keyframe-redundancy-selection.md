# 动态关键帧去冗余 · 新画面只有带来新信息才进长期记忆

## 一句话

用平均余弦相似度衡量长期记忆有多重复；候选替换后若重复度下降，就值得留下。

## 直觉

一小时会议截图若全是同一个人正坐着，留 30 张也没增加多少信息。更有用的做法是保留“正坐”“抬手看表”“拿起书”这些不同状态。InteractiveAvatar 用 SigLIP2 把画面变成语义向量，再比较这些向量是否太像。

## 怎么做的

一组真实帧 \(I_1,\ldots,I_n\) 先各自抽特征，再取平均成为候选描述向量：

\[
\mathbf s_{\mathrm{cand}}=\frac1n\sum_{j=1}^{n}f_{\mathrm{SigLIP2}}(I_j).
\]

长期池有 \(N\) 个向量。第 \(i\) 项与其余项目的平均余弦相似度为 \(\bar\rho_i\)，全池冗余度为 \(R\)：

\[
\bar\rho_i=\frac1{N-1}\sum_{j\ne i}\cos(\mathbf s_i,\mathbf s_j),\qquad
R=\frac1N\sum_{i=1}^{N}\bar\rho_i.
\]

候选试着替换一个槽位后重算得到 \(R'\)。若 \(R'<R\)，说明整池没那么重复，候选被保留；否则丢弃。

## 数字例子

为了能手算，设长期池只有 3 个单位向量，三对余弦相似度分别是 0.8、0、0.6。每对会在双重求和里出现两次，因此：

```text
R = 2×(0.8 + 0 + 0.6) ÷ (3×2)
  = 1.4 ÷ 3
  ≈ 0.467
```

候选替换后，三对相似度变成 0.1、0、0.2：

```text
R' = (0.1 + 0 + 0.2) ÷ 3 = 0.100
```

因为 0.100 < 0.467，新组合明显更不重复，候选应进入长期池。这个算例只说明论文的判据；论文没有公开多个槽位都可替换时怎样选最终槽位。

## 容易读错的地方

- “相似度低”在这里表示内容更多样，不等于画质更好。
- 这是语义新颖度启发式，不保证保存身份最关键的那一帧。
- 论文补充材料说阈值会沿用上一次选择得到的最小 \(R\)，但没有给完整更新伪代码。
