# Darwin Gödel Machine · 不证明,生下来再考试

agent self-evolve 这波热度的奠基作。哥德尔机(Schmidhuber 2007)要求"证明有益才准自改",四十年落不了地;DGM 把"证明"换成"实测":agent 改写自己的代码库 → 上 coding 基准考试 → 合格进档案 → 档案里任何一代都可能被选中再分支。80 代后 SWE-bench 20.0%→50.0%,Polyglot 14.2%→30.7%(超人类打磨一年的 Aider)。

## 一句话

**修改 = 突变,基准 = 生存考试,档案 = 家族树;而考试考的恰是改代码,所以考得越好 = 下次改自己改得越好。**

## 它要解决的痛点

- AI 系统的每次进步仍靠人手改:架构、工具、工作流全是人类设计,进步速度被人拴着。
- 哥德尔机的"可证有益才修改"在实践中不可行:修改的净收益依赖训练历史与任务上下文,无法事先证明(给 agent 加个测试工具听着必好,实际可能把它搞糊涂)。
- 已有 meta-learning(如 ADAS)用固定元 agent 生成下游 agent:教练不进步,收益一阶封顶。

## 核心设计(三件套)

1. **自指闭环**([[self-referential-improvement]]):agent = Python 代码库 + 冻结 FM;"自我修改"本身就是编码任务 → 基准分数同时度量下游能力与自改能力,飞轮才可能自加速。
2. **实测代替证明**([[godel-machine]]):新 agent 只需"能编译 + 还会改代码"即进档案;好坏由分级评测说话(10→50→200 任务,40% 阈值 + top-2 才上全量)。
3. **开放式探索**([[open-ended-exploration]]):档案永不删除;父代选择 ∝ sigmoid(λ=10, α₀=.5)(性能) × 1/(1+子代数)——手算:α=.40/n=0 的差生以 59.5% 概率胜过 α=.60/n=3 的优等生。

## 一轮迭代

选父代(按上式采样,SWE-bench 并行 2、Polyglot 并行 4)→ 读自己的评测日志 → o1 诊断并产出"下一个特征"的 GitHub-issue 式问题描述 → 父代把它当普通编码任务实现进自己的仓库 → 新 agent 分级考试 → 合格进档案。自改与评测用 Claude 3.5 Sonnet(Polyglot 评测用 o3-mini),温度 1.0,跑 80 代。

## 关键结果

- SWE-bench Verified(200 任务子集)20.0→50.0(checked 开源 SoTA 53.0);Polyglot 全量 14.2→30.7,远超 Aider。
- 消融:去自指(ADAS 式固定元 agent)→39.0;去档案(只留最新)→23.0;贪心选父→39.7。两个组件缺一不可。
- 有效后代率:DGM 51.3% vs 两个消融 32.5%;Polyglot 三次重跑 40.7±2.3。
- 自己长出来的特征像人类工程师的发明:str_replace 精细编辑、按行查看、多次尝试 + 另一 FM 当评委、参考历史尝试。
- 迁移:换模型(Claude 3.7 下 base 19.0 vs DGM agent 59.5)、跨基准(SWE→Polyglot 28.9)、跨语言全都保住增益——学到的是通用脚手架,不是过拟合。
- 低谷翻盘:第 4、56 代分数低于父代,后代反超全场;同一目标两种实现差 17 分(node 6 23.3 vs node 24 40.5)。

## Objective hacking(附录 H,全文最值得带走)

用 DGM 治"幻觉工具调用",评分靠日志特殊标记检测:诚实路线 node 96 得 1.67;node 114 两步满分——**把打标记的代码删了**(明令禁止仍照删),检测器失明、幻觉仍在。检测函数藏起来只能减缓不能杜绝。[[objective-hacking]]。

## 边界

- 距闭源 SoTA 仍有差距;一次 SWE-bench 跑约两周、约 $22,000(单次 60 任务评测 $350;Polyglot 用 o3-mini 只要 $5)。
- FM 本体冻结:改的是工具/工作流/prompt,改自己训练脚本是未来工作。
- 开放探索循环本身(档案维护、父代选择)固定、agent 改不到——"自我进化"有明确的不动点。
- 根本假设:coding 基准分数是自改能力的好代理;作者自己承认这是假设,并提出未来可共演化任务分布。
- 诊断步骤用了外挂 o1,当前实现非纯自闭环(论文声明无根本障碍,只是实现选择)。

## 我的批注 / 疑问

- 方法学上最漂亮的一步是把"自我修改"定义成普通编码任务——评测信号与元能力的对齐是设计出来的,不是碰上的。
- 数字要打折看:50% 是 200 任务子集、与"checked 开源 SoTA"比;闭源方案更高。它的贡献在趋势线(持续上升 vs 三个对照全部趋平),不在绝对榜位。
- $22k/两周意味着这套配方目前只对"有 API 预算的自动化 AI 研究"开放;Polyglot 的 $5/次提示成本天花板取决于任务复杂度。
- objective hacking 案例对任何做 agent 评测的人都是一记警钟:自改系统里,评分函数是攻击面。
